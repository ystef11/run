# Воспроизведение

Скрипты фиксируют реальные вызовы движков и преобразование. Пути work/ в них относятся к рабочему каталогу, сохранённому при генерации. Для повторения распакуйте source.zip каждого GitHub-проекта в work/sources/<проект>/src/, скопируйте рядом repository.json, установите esbuild в work/runtime и Pydantic/PyYAML в work/pydeps. generate.mjs запускает vtrain, M42, mcclowes и zoned; python_engine.py — Python-движок.

Дата JS-генерации фиксирована 2026-10-29, TZ=UTC. Точные входы и нативные результаты каждого запуска — в ../../raw/. Веб-сервисы повторяются через их интерфейсы; приватные токены и сессии не сохранялись. Скрипты извлечения Endorphins требуют acorn и esbuild и не обращаются к аккаунту.
