# Калькулятор беговых планов — правила и алгоритм

## 1. Назначение калькулятора

### 1.1. Цели

- Оценить текущее состояние спортсмена
- Спрогнозировать целевое время
- Дать возможность скорректировать цель
- Составить оптимальный план беговой подготовки под выбранную цель и выбранное целевое время с учетом прочих вводных и текущего состояния

Все описание и реализация не должны противоречить цели, а только дополнять. Если какой-то информации нет в открытых источниках, то необходимо находить причинно-следственные связи и использовать их

### 1.2. Область применения

Файл: `run_plan_calculator.html`. Используется в браузере и в приложении Runstef.
Ядро генератора — между маркерами `/*GEN-START*/` и `/*GEN-END*/`.

### 1.3. Условные обозначения

- **[метод.]** — правило из опубликованной методики (источник указан).
- **[практ.]** — практический порог: в методиках его нет, он выведен из причинно-следственной связи (она указана рядом).
- **Раздел** — структурная часть документа с полным номером, например 4.5.9.
- **Элемент тренировки** — разминка, рабочий отрезок, восстановление, заминка или блок повторений.

## 2. Принципы построения плана

**2.1.** **Универсальность.** Калькулятор не подгоняется под данные конкретного бегуна.

**2.2.** **Только методики.** Основа — Дэниелс, поляризованная, пирамидальная. Для того, чего в текущих методиках нет (ультра, горки, кросс, силовые, межсезонье), берутся другие опубликованные методики или причинно-следственные связи.

**2.3.** **Объём в минутах.** Объём планируется в минутах, в км переводится по распределению зон этого же плана (раздел 4.4).

**2.4.** **Прогноз — основа плана.** Результаты → профиль формы по дистанциям → прогноз на целевую дистанцию, акцент и темпы; объём и частота — по уровню 80/20 и тренировочной истории (5.4), цель объём не задаёт → состав тренировок. Лучший VDOT ограничивает профиль сверху, но не заменяет остальные результаты. Прогноз не выводится из уже составленных тренировок.

**2.5.** **Две модели:**

  - модель 1 (реалистичная) — ориентир времени и траектория формы по профилю имеющихся результатов (5.3); не зависит от введённой цели; заполняет форму рекомендациями;
  - модель 2 (фактическая) — план строится от введённого времени цели: траектория формы и темпы приводятся к цели единым приростом VDOT на всех дистанциях (5.3). Если цель за границами модели 1, выводится только предупреждение, план строится всё равно.

**2.6.** **Поправки на трассу** (жара, высота, набор высоты) меняют только время. VDOT и объём от них не меняются.

**2.7.** **Значения по умолчанию в форме сохраняются** — так удобнее заполнять. При этом модель на них не настраивается.

**2.8.** **Относительные величины.** Окна и сдвиги темпов задаются долей скорости, а не секундами: 6 с — это 2,5% скорости при 4:00/км и 1,7% при 6:00/км.

**2.9.** **Один алгоритм.** Форма и план считаются одним кодом (`buildPlan`): форма и план используют один результат расчёта профиля и прогноза; пик и число пробежек берутся из собранных недель. Пик объёма в км форма берёт из плана (километры построенных недель). Объём строится сразу правильным — неделя за неделей по собранным неделям, без урезания недель после построения.

**2.10.** **Минуты недели задаёт только кривая (раздел 4.4).** Состав недели подбирается под них; порядок уступок, когда минуты не вмещаются, — раздел 4.5.9. Методические лимиты **[метод.]** не нарушаются. Недобора в плане нет: если неделя не вмещает минуты, объём недели в кривой уменьшается до вмещающегося, с примечанием и причиной.

**2.11.** **Деление по специфике и акцент.** Сначала общая часть плана — рост объёма и длительности; затем подключается специфика (вставки в длинной, M, T). Поддерживающая доза качества — нижняя граница вытеснения: акцент на западающем качестве получает остаток бюджета, но не может снизить дозы остальных качеств ниже этой границы (5.5).

**2.12.** **Тренировка сразу допустима.** Назначение, полная длительность, рабочие отрезки, темп и паузы выбираются совместно из бюджета и истории прогрессии. Длинная со вставками — единый формат: сначала укорачивать готовую длинную ради добавленных вставок нельзя.

**2.13.** **Тренировки не рассматриваются по отдельности.** Все занятия недели и блока влияют друг на друга: на бюджет интенсивности и вытеснение качеств, на восстановление между тяжёлыми днями, на последовательность прогрессии и нагрузку. Любое решение по одной тренировке (тип, доза, день, число пробежек) проверяется по влиянию на остальные.

**2.14.** **От общего к частному.** План строится от общих принципов к частным. Частные правила не должны нарушать общие принципы. Нарушение этого правила - критическая ошибка!

## 3. Входные данные

### 3.1. Поля формы

| Поле | Смысл |
|---|---|
| `startISO`, `goalISO` | Начало плана и дата главного старта. Неделя 1 начинается с понедельника; если план стартует позже понедельника, неделя 1 неполная |
| `goalDist` | Дистанция: 5 / 10 / 21,1 / 42,2 км, ультра 60–160 км |
| `results[{dist,sec}]` | Недавние результаты; VDOT считается для каждого, профиль формы по дистанциям ограничен лучшим VDOT |
| `ltPace`, `lthr` | Темп и пульс ПАНО. Темп задаёт порог; без результатов форма считается по нему |
| `tgtGoal` | Время цели, показываемое пользователю (с учётом трассы) |
| `curVol` + `volUnit` (`km`/`h`) или `curMin` | Текущий объём, среднее за 4 недели |
| `peakVol` | Пик объёма; передаётся только если задан вручную, иначе — целевой пик раздела 4.4 |
| `runs`, `runsAuto` | Пробежек в неделю, 3–12. `runsAuto` — число подбирает план (раздел 4.5); ручное значение не превышается |
| `curLong`, `maxLongCap` | Привычная длинная (самая длинная за 30 дней; от неё рост ≤ +10%/нед, короче не делается) и максимальная длинная, мин |
| `slider` | Распределение: 0 — поляризованное, 1 — пирамидальное |
| `deload` | Недели Б: `need` — по необходимости, `w31` — 3:1, `none` — без недель Б (откат длинной А остаётся) |
| `tuneRaces[{iso,dist}]` | Промежуточные старты |
| `autoTest` | `false` — не ставить контрольный тест |
| `cross[{sport,cls,mins,days,auto}]` | Кросс-тренировки (лыжи, бассейн, вело, фитнес): класс К1–К4, длительность, фиксированные дни и/или «авто» |
| `strength` | Силовых в неделю, 0–3. По умолчанию — по правилу 5.6; введённое вручную не меняется |
| `longDow` | День длинной; по умолчанию — день недели старта |
| `elevGain`, `localHills`, `altitude`, `heat` | Трасса. Рельеф для горок (5.5): `localHills` (короткие крутые подъёмы при малом среднем наборе) или набор ≥ 8 м/км **[практ.]** |
| `preCtx` | Что было перед планом: `none`, `race` (недавняя гонка: `preRaceDate`, `preRaceDist`), `transition` (переход с другой программы: `transPeakVol` — км её пиковой недели, `transWeeksAgo` — сколько недель назад) |
| `maxVolEver` | Наибольший недельный объём в прошлом, км — для примечания |
| `histLoads`, `lpm` | Из приложения. `histLoads` — недельная нагрузка Garmin за 4 недели до плана (4 значения, от старой к новой; разрыв до начала плана — 5.8). `lpm` — нагрузка в минуту бега `{easy, long, thr, vo2}` (лёгкий, длинная, порог, МПК); без `lpm.easy` калибровки нет |
| `age`, `sex`, `exp` | Профиль. `exp`: `novice` (до ~2 лет бега или первый старт на дистанции), `inter` (2–4 года), `adv` (многолетний стаж); влияет на фазу I (5.2), долю Z3–Z5 (5.4), число силовых (5.6) и межсезонье (раздел 6). HRmax = 208 − 0,7·возраст (м, [Tanaka 2001](https://pubmed.ncbi.nlm.nih.gov/11153730/)), 206 − 0,88·возраст (ж, [Gulati 2010](https://pubmed.ncbi.nlm.nih.gov/20585008/)) |
| `planMode`, `owWeeks` | Режим: `goal` — план под цель, `offseason` — межсезонье (раздел 6). `owWeeks` — длительность межсезонья, 2–8 нед; по умолчанию — рекомендация по опыту и объёму (раздел 6) |
| `tag` | Префикс названий тренировок для выгрузки; пустой — случайный `[GENxxxx]` |

### 3.2. Автозаполнение из приложения

Runstef (`ToolUrlBuilder.kt`) передаёт параметры после `#`; старые ссылки с `?query=` тоже работают.

Что передаётся:

- возраст, пол — из локального профиля (Garmin их не хранит);
- ПАНО;
- недельный объём `curvol` (км) и `curmin` (минуты бега за неделю, среднее за 4 недели). `curmin` приоритетнее: из него форма берёт часы;
- лучшие недавние результаты;
- история нагрузки и калибровка для ACWR.

Все поля можно править вручную. Без параметров работают значения формы по умолчанию.

### 3.3. Проверка противоречивого ввода

Ошибки:

- пульс ПАНО выше расчётного HRmax или ниже 110;
- темп ПАНО медленнее 10:00/км (ошибка формата);
- дата главного старта не позже начала плана или уже прошла;
- время цели не разбирается.

Предупреждения:

- **скорость на ПАНО расходится со скоростью порога по результатам больше чем на 3%** — в обе стороны. Быстрее: Garmin нередко подставляет порог из недавних 10 км, а ПАНО — это темп, который держится около 60 мин (порог Дэниелса). Медленнее: результаты устарели или ПАНО определён неточно;
- текущий объём больше пика; минимальная длинная больше максимальной;
- ручное число пробежек, для которого нет размещения (раздел 4.6): план строится с наибольшим числом, для которого оно есть, с примечанием;
- набор больше 60 м/км;
- разброс VDOT по результатам больше 4;
- пробежек и тренировок кросса (фиксированные дни и «авто») больше 7: кросс встанет вторым в дни бега, а где места нет — не будет поставлен.

### 3.4. Ручной ввод

- Поле, изменённое вручную, больше не пересчитывается автоматически.
- Любое изменение исходных данных сбрасывает все ручные значения в «Параметрах плана».
- Кнопка «↻ Авто» снимает ручной ввод цели.
- Ручной пик выше достижимого подсвечивается.
- Форма пересчитывается через 150 мс после последнего изменения.

## 4. Алгоритм — порядок расчёта

Порядок расчёта: текущая форма (раздел 4.1) → календарь (раздел 4.2) → прогноз и цель (раздел 4.3) → объём и бюджет (раздел 4.4) → состав, размещение и заполнение (разделы 4.5–4.7) → контроль нагрузки (раздел 4.8) → оформление (раздел 4.9). Расчёты из разделов 4.4–4.8 выполняются для каждой недели до её принятия; при подборе допустимой недели расчёт повторяется. К следующей неделе переходят после принятия предыдущей. Собранный план не меняет исходный прогноз. Подробные правила расчёта приведены в разделе 5.

### 4.1. Текущая форма и акценты подготовки

Задача: определить текущую форму на разных дистанциях, западающие качества и расчётную форму на целевой дистанции.
Вход: результаты стартов, ПАНО, целевая дистанция.
Расчёт:
- Для каждого результата определить VDOT. Повторные результаты одной дистанции отобрать по правилам сопоставимости.
- По результатам на разных дистанциях построить индивидуальную зависимость времени от дистанции. Лучший VDOT использовать как верхнюю границу формы.
- Сравнить результаты: определить, на каких дистанциях форма ниже этой границы и насколько. Отставание на длинных дистанциях указывает на дефицит выносливости, на коротких — скорости.
- По индивидуальной зависимости оценить текущее расчётное время и соответствующий VDOT на целевой дистанции.
- Определить акценты подготовки с учётом выявленного дефицита и целевой дистанции.

Пример: результаты 10 км за 56 минут и полумарафона за 2:09 показывают снижение формы с ростом дистанции. Расчётный марафон должен учитывать это снижение: перенос лучшего VDOT с 10 км завысит оценку возможностей. Основной акцент — выносливость.

При результате только на одной дистанции индивидуальный профиль неизвестен: используются эквиваленты Дэниелса с соответствующей оговоркой. Без результатов — оценка по ПАНО.

Выход: профиль текущей формы, выявленные дефициты, акценты подготовки, расчётные время и VDOT на целевой дистанции. Изменение формы за срок подготовки рассчитывается в разделе 4.3.

### 4.2. Календарь

Задача: определить срок подготовки, распределить фазы и закрепить даты, которые ограничивают состав и размещение тренировок.
Вход: даты начала и главного старта, целевая дистанция, текущая форма из раздела 4.1, тренировочная история, промежуточные старты и фиксированные дни кросс-тренировок.

Расчёт:
- Закрепить все тренировки по выбранным пользователем дням, включая длинную, кросс-тренировки и силовые. Для занятий без выбранного дня оставить свободными и расставляются далее при составлении расписания недели в разделе 4.6.
- Определить число календарных недель подготовки, выделить неполную первую неделю и период подводки к главному старту.
- Для выбора фаз предварительно определить уровень объёма и целевой пик по текущему объёму и тренировочной истории, используя уровни планов [80/20 Endurance](https://www.8020endurance.com/training-plans/marathon/). Ручной целевой пик использовать вместо расчётного. Правила — раздел 5.4.3.
- Определить необходимость базовой фазы: учесть опыт, возвращение после перерыва и требуемый рост объёма. Распределить рабочие недели между фазами по [методике Дэниелса](https://us.humankinetics.com/products/daniels-running-formula-4th-edition) и правилам раздела 5.2. Подводку включить в заключительную фазу.
- Разместить промежуточные старты. Исключить с пояснением те, после которых восстановление не заканчивается до главного старта.
- При выполнении условий раздела 5.2 назначить контрольный тест за 21 день до главного старта.
- Отметить предстартовые дни и периоды восстановления по правилам раздела 5.2, включая восстановление после недавней гонки до начала плана.

Выход: календарь недель с фазами, подводкой, стартами, контрольным тестом, периодами восстановления и фиксированными занятиями; уровень объёма и целевой пик.

Объём недель и достижимый пик рассчитываются в разделе 4.4.

### 4.3. Прогноз и цель

Задача: оценить возможное изменение текущей формы за срок подготовки и определить траекторию формы для построения плана.
Вход: профиль текущей формы и акценты из раздела 4.1, календарь из раздела 4.2, выбранное время цели.

Расчёт:
- От текущей формы построить исходную траекторию её изменения за рабочие недели подготовки. Учесть разрывы между результатами на разных дистанциях и ограничения роста из раздела 5.3. Подводка прироста формы не добавляет.
- По форме на целевой дистанции к концу подготовки определить прогнозируемое время. Использовать его как цель по умолчанию.
- Если пользователь изменил цель, скорректировать исходную траекторию: более быстрая цель требует большего прироста формы, более медленная — меньшего. Исходная текущая форма сохраняется. Если цель медленнее текущей расчётной возможности, снижение формы не закладывается.
- Если цель выходит за возможности исходного прогноза, вывести предупреждение. План строить под выбранную цель, сохраняя исходный прогноз для сравнения.
- По выбранной траектории определить тренировочные темпы на каждую неделю. Акценты подготовки брать из раздела 4.1 с учётом изменения профиля формы.
- Поправки на трассу применять к времени целевого старта.

Выход: исходный прогноз времени, выбранная цель, траектория формы и тренировочные темпы по неделям, предупреждения о расхождении цели с прогнозом.

Прогнозное время не пересчитывается по уже составленным тренировкам.


### 4.4. Объём и зоны

Лимиты недели заданы в км, а км зависят от распределения по зонам; они рассчитываются совместно.

**4.4.1.** **Распределение интенсивности.**  
Задача: определить бюджеты интенсивности с учётом акцента подготовки из раздела 4.1. Модели по умолчанию до 10 км — поляризованное, длиннее — пирамидальное
- По акценту рекомендовать положение ползунка между поляризованным и пирамидальным распределением:
 - при дефиците выносливости — смещение к пирамидальному;
 - при дефиците аэробной мощности и скорости — смещение к поляризованному;
 - если выраженный дефицит не выявлен или данных недостаточно — исходное распределение по целевой дистанции.
- Выраженность дефицита определяет степень смещения. Это практическое правило калькулятора; порядок расчёта задаётся в разделе 5.4.1.
- Пользователь может изменить рекомендованное положение. Выбранное распределение задаёт бюджеты интенсивности; акцент из раздела 4.1 определяет назначение тренировок внутри этих бюджетов.
- При расчёте недельных бюджетов учитывать фазу подготовки и опыт. Сначала резервировать поддерживающие дозы необходимых качеств, затем распределять остаток на развитие акцента.
- Дефицит выносливости учитывать также при выборе объёма лёгкого бега и длительности длинной. Смещение ползунка не заменяет эту работу.
- В базовой фазе использовать Z1–Z2 с предусмотренными ускорениями. Фактическое распределение Z1–Z5 рассчитывать по составленным тренировкам.

**4.4.2.** **Целевой пик:** берётся из раздела 4.2; при построении кривой проверяется его достижимость. Результат — достигнутый пик, который может быть ниже целевого.

**4.4.3.** **Кривая роста без плато.** Пик — последняя рабочая неделя перед подводкой. Прибавка каждой недели = (пик − объём прошлой рабочей недели) / число оставшихся рабочих недель (без оставшихся разгрузок). Ограничения:

  - ACWR ≤ 1,3 ([Gabbett 2016](https://bjsm.bmj.com/content/50/5/273), раздел 5.8);
  - **минимальная неделя [практ.]:** 3 пробежки по 30 мин = 90 мин. Нижней границы объёма для ACWR в источниках нет (Gabbett 2016; [Impellizzeri et al. 2021](https://doi.org/10.1007/s40279-020-01378-6); [Nakaoka et al. 2021](https://doi.org/10.1007/s40279-021-01483-0), Sports Med 51(11):2437–2447 — у бегунов более высокий ACWR не был связан с более высоким риском травм). Ниже минимальной недели одна добавленная пробежка по 30 мин даёт рост нагрузки больше 30% (с 2 до 3 пробежек — +50%), поэтому хроническая нагрузка в знаменателе берётся не меньше нагрузки минимальной недели, а знаменатель правила двух недель — не меньше км минимальной недели. Так план строится и от нулевого, и от малого текущего объёма;
  - беговые км недели ≤ 1,3 × км недели i−2 ([Nielsen et al. 2014](https://vbn.aau.dk/da/publications/excessive-progression-in-weekly-running-distance-and-risk-of-runn): у начинающих рост больше 30% за 2 недели связан с большей частотой травм, но в целом различие не значимо; для травм, связанных с дистанцией, HR 1,59, ДИ 0,96–2,66); опорная неделя — i−2, а если в ней старт, предстартовые дни или окно восстановления — ближайшая более ранняя без них.

Если ограничения не дают дойти до целевого пика, пик кривой ниже, выводится примечание с причиной.

**4.4.4.** **Волна разгрузок** — три слоя; глубина разгрузки — результат состава недели, а не отдельный параметр. Основание — эталонные планы (Garmin, Higdon, Hansons; числа — `plans/sample/COMPARISON.md`, 5.6); пороги ориентировочные: откатов длинной в файлах 37, недель Б у Garmin 8.

  - **А. Откат длинной [практ.]:** в неделю роста, следующую за неделей с длинной ≥ 142 мин, длинная = 65% предыдущей (в эталонах −30…−40%); остальные пробежки и минуты Z3–Z5 не меняются (объём недели −5…−16%). Откат не ставится две недели подряд, в неделях Б, подводки, старта, окна восстановления. Порог 142 мин — Hansons («через неделю при длинной ≥ 142 мин»); доля недель с откатом растёт с длинной прошлой недели: < 90 мин — 6%, 90–120 — 12%, 120–150 — 29%, 150–180 — 53%, ≥ 180 — 64%.
  - **Б. Неделя восстановления:** длинная −38%, остальные пробежки −11%, минуты Z3+ −23% (Garmin); число пробежек и Q не меняется. Объём недели получается −17…−22%. Режимы `deload` и периодичность — раздел 5.4. После недели Б рост продолжается от последней рабочей.
  - **В. Подводка** — раздел 4.4.6. Предварительная подводка заменяет последнюю неделю Б: в её окне Б отдельно не ставится.

**4.4.5.** **Недели промежуточных стартов и теста** (главный старт — раздел 4.4.6 и раздел 5.4) — подводка внутри кривой и по дням: 7 дней до старта (день старта входит) идут на 80% рабочего объёма, доля календарной недели — среднее по её дням (старт не в воскресенье → неделе до старта достаётся часть подводки, пример: старт в понедельник — 83%). Неделя самого старта: объём недели = 80% последней рабочей (Пфитцингер, [Advanced Marathoning](https://us.humankinetics.com/products/advanced-marathoning-3rd-edition): недели с промежуточными стартами 45→37 и 54→43 — это −18% и −20%). Такая неделя заменяет неделю Б (счёт недель роста до следующей недели Б начинается заново), в пик кривой не входит; рост после неё продолжается от последней рабочей недели. Если вместо рабочей недели получилась неделя с метками (предстартовые дни, окно восстановления) или с долей подводки к старту и её объём вышел ниже последней рабочей, последняя рабочая не меняется.

**4.4.6.** **Подводка (слой В)** — предварительная подводка, затем основная неделя: марафон и ультра 72 / 58 / 22% пика, остальные дистанции 88 / 40% **[практ.]**. Эталоны: 5–10 км и полумарафон — предпоследняя неделя 85–90% пика (разброс 74–96), неделя старта ≈ 40% (29–50); марафон 72 / 58 / 22 (Hansons 88 / 87 / 45). Предварительная подводка отдельно виден только у Garmin и BHF; для ультра эталонов нет — как у марафона. Пфитцингер даёт 80/60/40 для марафона; [Bosquet et al. 2007](https://pubmed.ncbi.nlm.nih.gov/17762369/): 8–14 дней, объём −41…60%, интенсивность и частота сохраняются. Состав подводки: интенсивность и частота сохраняются, объём падает ([Bosquet 2007](https://pubmed.ncbi.nlm.nih.gov/17762369/): 2 недели, объём −41…60%). Длинная марафона — 82% пиковой в первой неделе и доля подводки (58%) во второй: у Пфитцингера последняя 20-мильная за 3 недели до старта, затем 16–17 миль ([обзор 18/55](https://buenavida.run/plans/pfitz-am-18wk-up-to-55/)), у [Runner's Connect](https://runnersconnect.net/how-to-taper-for-a-marathon/) 80–85% и 50–60% (авторская рекомендация). Для 5–10 км и полумарафона источника не найдено **[практ.]**: в эталонах (21 план) длинная ≈ 74% базы при объёме 89% — берётся доля подводки × 0,85. Цели Z3+ (минуты, 0,9 — из эталонов: медиана 92% базы; источник задаёт только сохранение интенсивности и частоты) (раздел 4.4.7) не ниже 0,9 целей последней недели роста (откат А не считается). Для ультра эталонов нет: длинная — как у марафона, цели Z3+ остаются долей объёма (при сохранении они давали 3 тяжёлых тренировки при бюджете 2). Реальный объём недели старта (что вмещает собранная неделя) не проверен — раздел 5.4.

**4.4.7.** **Цели недели:** средняя и верхняя цели = доли модели × kexp (5.4) × минуты недели (остальное — Z1+Z2); минуты Z3 и Z4 расходуют среднюю цель, Z5 — верхнюю (5.4); км недели — по темпам зон. Интенсивный кросс (К2) расходует цели по тому же правилу. В неделях подводки (кроме ультра) цели не ниже 0,9 целей последней недели роста: интенсивность сохраняется при падении объёма (раздел 4.4.6).

- **Построение по неделям.** Для недели i: объём по разделам 4.4.3–4.4.6 и бюджет по разделу 4.4.7 → состав и размещение (разделы 4.5–4.6) → запись готовых тренировок (раздел 4.7) → контроль нагрузки (раздел 4.8). Проверяются ограничения раздела 4.4.3 по собранной неделе: её нагрузка (раздел 4.8) и её беговые км. Если неделя не проходит, берётся наибольший объём, при котором собранная неделя проходит (поиск делением пополам по объёму недели). Неделя проходит также только если вмещает свои минуты (недобор < 10 мин): иначе объём уменьшается снижением на 3% до вмещающегося. То же для недель подводки: доля пика уменьшается, если неделя с метками её не вмещает. Неполная неделя 1 (день старта плана не с понедельника) этому не подчиняется: её объём задан днями. Так ACWR и правило двух недель входят в кривую сразу, а не исправляются после. История ACWR и опора правила двух недель — собранные недели. Минуты недели после этого не меняются.
- **Неделя старта или теста:** в проверке ACWR нагрузка самой гонки не учитывается — её не убрать; в историю следующих недель она входит. Число пробежек недель с метками не больше, чем в прошлой обычной неделе (неполная неделя 1 не считается обычной).
- Выход: минуты, средняя и верхняя цели и км каждой недели; достигнутый пик кривой (идёт в форму и подводку; исходный прогноз не пересчитывается).

### 4.5. Состав недели

- Вход: минуты и цели зон недели (раздел 4.4), фаза (раздел 4.2), темпы (раздел 4.3), дни-метки и кросс в фиксированные дни.
- **Порядок (разделы 4.5–4.6):** ① фиксированные занятия и бюджет недели; ② поддерживающие дозы необходимых качеств за блок; ③ развивающие дозы с учётом дистанции, профиля результатов и предыдущих тренировок; ④ совместный выбор допустимых форматов и числа пробежек; ⑤ шаблон и раскладка готовых тренировок. Длинная и её вставки выбираются одним форматом до размещения.
- **Доли типов:** фиксированные занятия расходуют бюджет первыми; оставшийся бюджет распределяется между поддержанием и развитием необходимых качеств. Длинная, средне-длинная и качественные выбираются совместно в пределах этого распределения; лёгкие и восстановительные заполняют остаток. Назначение занятия важнее заполнения доли зоны.

**4.5.1.** **Фиксированное:** старт или тест, предстартовые дни, окно восстановления, кросс в фиксированные дни.

**4.5.2.** **Длинная** — лимит Дэниелса: ≤ 25–30% недельного километража (при < 6 пробежек — с поправкой на частоту, 5.5) и ≤ 150 мин (кроме ультра); прогрессия +10 мин в неделю (Пфитцингер), но не больше +10% к прошлой (дискретность 5 мин, раздел 5.5), в неделях А и Б — по волне раздела 4.4.

**Марафон и ультра:** длинная — специфическая работа; её развивающая доза не вытесняет поддержание остальных необходимых качеств. Ориентир марафона — 2–2,5 ч (Дэниелс); потолок ультра `ultraLong` — раздел 5.5. Доля длинной до 40% недели (вместо 25–30%) **[практ.]**, от числа пробежек не зависит: у Пфитцингера (18/55) в первой неделе 12 из 33 миль, ~36%.

**4.5.3.** **Бюджет качественных** (Дэниелс 2Q): фаза I — 0, фазы II–IV — 2, при 3 пробежках — 1, при ≥ 7 пробежках (заданных или выведенных) — 3 **[практ.]**: две качественные и длинная из трёх пробежек не оставляют лёгкого дня для восстановления между тяжёлыми; в планах Garmin при 4–5 пробежках обычно две Q, при 7–9 — по названиям три (17 из 23 недель с 7–9 пробежками), но по минутам Z3+ полных Q (≥ 25 мин Z3+) три лишь в 1 из 23 недель: третья — лёгкий стимул (горки, смешанный порог, 5–24 мин Z3+) в 12 из 23 недель. **Отступление от рекомендаций:** Дэниелс — две качественные в неделе, включая длинную ([обзор](https://runningwithrock.com/marathon-training-plan-jd-2q/)); в плане 5–10 км до трёх Q вместе с длинной; Hansons — 3 SOS-дня, длинная входит. Три отдельные Q плюс длинная дают до 4 тяжёлых дней — так только в Garmin. Расчёт ставит третью Q полной дозой, у Garmin она лёгкая (см. выше). Оставлено ради доли Z3+ (при двух Q на 7–8 пробежках 7–12% против 10–21% в эталоне); цена — Q накануне длинной (при двух Q таких недель в 5 раз меньше: 171 против 963 на 600 конфигурациях). Пересмотреть, если доли Z3+ удастся достичь двумя Q. Проверена лёгкая третья Q (≤ 24 мин работы, как у Garmin): доля Z3+ в третьей четверти падает с 17 до 14% (Garmin ПМ-8, эталон 21%) и с 16 до 14% (Garmin М-7, эталон 18%), так как дозы двух остальных Q ограничены лимитами Дэниелса, — не принято. Третья Q помещается только в запасном шаблоне (5.6.3). Бюджет расходуют по одной:

  - старт или тест недели;
  - настройка за 5 дней до главного старта (в неделе старта или в предыдущей);
  - интенсивный кросс (К2) как отдельный качественный день;
  - длинная со вставками (Q1);
  - беговые качественные. Допустимая пара К2 + Q определяется при составлении доз: нагрузка обоих занятий входит в бюджет, пара занимает один качественный день; возможность её размещения — ограничение выбора шаблона;
  - средне-длинная с отрезками T;
  - К2 «авто» без пары (раздел 4.6).

Если пробежек в неделе вышло 3 при большем допуске (объём мал), бюджет — как при 3 пробежках.

**4.5.4.** **Длинная со вставками** — единый формат, а не добавление к готовой лёгкой длинной. По назначению недели и предыдущим дозам сразу выбираются полная длительность, лёгкая часть, T/M-вставки и паузы в пределах общего бюджета, лимита км и прогрессии. Только у марафона (фаза III — T, фаза IV — M) и ультра (фаза IV — целевой темп), типы — 5.5; у остальных дистанций длинная без вставок. Доза не определяется одной фазой.

**4.5.5.** **Качественные** выбираются по назначению и последовательности протокола: сначала предусмотренные блоком поддерживающие работы, затем развивающие. Для каждого назначения хранится предыдущая доза; следующая — продолжение её прогрессии в пределах бюджета. Повторение разрешено. Если развивающая ступень не помещается, выбирается допустимая повторная или уменьшенная доза того же назначения.

  - Типы: T, M, **steady** — бег в зоне Z3 от темпа M до середины между M и T, непрерывно; I, R, темп гонки, **горки** — обычный тип Q.
  - Бюджет: M и steady — Z3, T и темп полумарафона — Z4, I/R/горки — Z5; темп 5–10 км — по границе Z4/Z5 (5.4); цели расходуются по зонам (Z3 и Z4 — средняя, Z5 — верхняя). Общий лимит зоны не делает назначения взаимозаменяемыми. Дефицит одного качества не отменяет поддержание остальных.
  - Набор необходимых качеств определяется целевой дистанцией и профилем результатов; уровень объёма ограничивает дозу и частоту. Он не исключает развитие или поддержание качества автоматически. Допустимые протоколы и минимальные дозы — раздел 5.5.

**4.5.6.** **Средне-длинная** — полумарафон (по Пфитцингеру), марафон и ультра (у ультра — спарка накануне длинной), 60% длинной (Пфитцингер), если ≥ 60 мин и недельный объём ≥ 50 км **[практ.]**: самый лёгкий уровень планов Пфитцингера на полумарафон — 31–47 миль в неделю (≈ 50–76 км), «начинающим не подходит» ([обзор](https://runningwithrock.com/pete-pfitzinger-half-marathon-plans/)); при меньшем объёме средне-длинная отнимает минуты у лёгких пробежек (в планах Garmin 4–5 пробежек средне-длинной нет). У марафона в фазах III–IV Q2 может идти внутри средне-длинной — средне-длинная с отрезками T (в марафонских планах 2Q Дэниелса Q2 — длинная лёгкая работа с пороговыми отрезками); это единый заранее выбранный формат MQ; он не назначается ради вместимости шаблона. Средне-длинная не вытесняет лёгкие пробежки **[практ.]**: она ставится, только если остаток недели после длинной и Q вмещает остальные пробежки по минимуму (30 мин; 20 мин при заданном вручную числе, 4.5.12); у ультра спарка укорачивается до остатка (не короче половины и 60 мин). Иначе неделя превышала минуты кривой на 20–40 мин, а лишние пробежки молча отбрасывались.

**4.5.7.** **Кросс «авто»** — занятие с заданными дозой и допустимыми сочетаниями, без фиксированного дня (раздел 4.6).

**4.5.8.** **Лёгкие и восстановительные** — ровно остаток минут, наименьшим числом пробежек, но не меньше достигнутого (число пробежек, раздел 4.5.12). Иерархия длительностей: длинная ≥ средне-длинная ≥ лёгкая ≥ восстановительная. Лёгкая — от 30 мин (Дэниелс) до min(средне-длинная, 60% длинной); восстановительная — от 30 мин, не длиннее лёгкой и ~8 км в медленном конце E (Пфитцингер). Количество и дозы вторых пробежек заданы составом, их дни выбираются в разделе 4.6. Минуты каждой лёгкой и восстановительной определяются здесь, до шаблона: длинная со вставками считается раньше лёгких (округление вставок уходит в лёгкие); остаток раздаётся «водой» — общий уровень для всех, каждая не выше своего потолка, кратно 5 мин; пробежка не короче 30 мин, если остаток не делится — перебор до 10 мин; остаток меньше лёгкой уходит в разминки качественных (раздел 4.5.9.4). Ускорения (4 × 20 с) назначаются двум самым длинным лёгким от 35 мин (при равенстве — в порядке состава), не восстановительным; они входят в минуты этих пробежек. Их Z5 (80 с на пробежку) входят в верхнюю цель недели и назначаются последними, из остатка цели после качественных; в фазе I (верхняя цель равна нулю) — в пределах 160 с в неделю как единственная быстрая работа фазы (5.2); не хватает остатка — ускорений меньше или нет. Шаблон эти значения не меняет.

**4.5.9.** **Остаток не вмещается** — по порядку, пока не вместится:

**4.5.9.1.** число пробежек не задано — +1 лёгкая пробежка в состав, до предела доступных дней и дней уровня 80/20; затем выбирается размещение;

**4.5.9.2.** дни бега исчерпаны (число пробежек равно дням бега уровня) — практические пороги уступают: восстановительные дни становятся лёгкими; потолок лёгкой «60% длинной» **[практ.]** поднимается до средне-длинной, без неё — до длинной (иерархия сохраняется). Порог уступает раньше второй пробежки: он меняет длительность, а вторая пробежка — частоту;

**4.5.9.3.** пороги не помогли — вторые пробежки дня (раздел 4.6), по одной за раз, пороги в обычном виде; если не вмещает и это — пороги уступают снова (так же при числе пробежек, заданном вручную, в неделе старта или восстановления);

**4.5.9.4.** остаток меньше 30 мин — в разминки качественных, до +10 мин каждой (в день со второй пробежкой — в пределах суммы дня);

**4.5.9.5.** что осталось — неделя не вмещает свои минуты: сборка возвращает недобор, а кривая (раздел 4.4) уменьшает объём недели до вмещающегося и пишет примечание с причиной: какие лимиты методики его дали (длинная ≤ 25–30% недели и ≤ 150 мин, остальные пробежки не длиннее длинной), дни старта и окно восстановления. Ручное число пробежек не превышается: это расписание пользователя, примечание просит добавить пробежку.

**4.5.10.** **Размещения нет ни при одном допустимом числе пробежек** — сначала проверяется запасной шаблон 5.6.3 (Q накануне L), затем состав упрощается по порядку ниже. После каждого изменения заново перебираются числа пробежек и размещения (раздел 4.6); берётся первый успех. Порядок — от потери, которая не затрагивает бегового стимула, к потере стимула; методические лимиты **[метод.]**, фиксированный календарь и минуты недели из кривой не уступают:

**4.5.10.1.** К2 «авто» заменяется на К1 (кросс — не беговой стимул; фиксированные дни кросса не меняются);

**4.5.10.2.** Q, которые протокол позволяет (5.5), переносятся внутрь длинной или средне-длинной (LQ, MQ): тяжёлый день освобождается, стимул сохраняется;

**4.5.10.3.** убирается M (средне-длинная, кроме явной ультра-спарки): отдельного стимула у неё нет, её минуты идут в лёгкие по разделу 4.5.9;

**4.5.10.4.** число Q (и ультра-спарка) уменьшается на одну, пока размещение не найдено; слот теряет тот, чья потеря наименьшая по правилу слотов (5.5): сначала развивающая часть акцента, затем качество с наибольшим запасом до предела интервала `n_max − возраст стимула` (`n_max = min(3, 1/f)`; для `f` = 2/3 запаса нет), при равенстве — стоящее позже в порядке фазы. Доза оставшихся Q и граница `f` не меняются; интервал **[практ.]** для пропущенного качества может быть превышен — это примечание «качество X пропущено» с причиной (какие занятия, даты или интервалы несовместимы);

**4.5.10.5.** при нулевом числе Q размещение существует всегда (остаются фиксированные занятия, длинная и лёгкие); если не хватает дней для минут — раздел 4.5.9.5.
Минуты недели при этом не меняются: минуты снятых занятий идут в лёгкие, вместимость — раздел 4.5.9. Средняя и верхняя цели — бюджеты, а не обязательства: недобор допустим.

**4.5.11.** **Вместимость недели** — сумма потолков её тренировок при данном числе пробежек (+ до 10 мин к разминке каждой качественной).

**4.5.12.** **Число пробежек:** наименьшее, при котором неделя вмещает свои минуты, **но не меньше привычного**: частота не падает, «наименьшее число» действует только вверх **[практ.]**. Привычное число в первой неделе — текущий объём ÷ 70 мин (средняя пробежка), округляется к ближайшему целому, не меньше 3 и не больше предела дней уровня 80/20; дальше — наибольшее число пробежек обычных недель и подводки (в пределах предела дней). Причина: при «наименьшем числе» дистанция отдельной пробежки растёт — это скачок дистанции одной пробежки ([Frandsen et al. 2025](https://pure.au.dk/portal/en/publications/how-much-running-is-too-much-identifying-high-risk-running-sessio/); числа — 5.5, «Справочно»). Число ограничено доступными днями, пределом уровня и допустимыми вторыми пробежками (раздел 4.6). **Минимум пробежки [практ.]:** 30 мин; при заданном вручную числе пробежек — 20 мин, чтобы число не сбрасывалось в малые недели (в 20 из 21 эталонов 10-й процентиль длительности пробежки ≥ 30 мин, самая короткая ≤ 20 мин — в 13 из 21; Great Run 10 км — 20 мин при 4 пробежках). Для каждого рассматриваемого числа заранее определяются состав и дозы; размещение должно существовать. Если ни один состав не вмещает объём — далее раздел 4.5.9.2. Длинная от числа пробежек не зависит (раздел 4.5.2); число подбирается перебором от привычного (не от 3). Лёгкие по 30 мин (минимум) нижней границы не отменяют: если остаток минут не даёт лёгких по 30 мин, пробежек меньше. Недели с метками календаря (старт, предстартовые дни, окно) и тест — число пробежек по их правилам. В неделях со стартом, предстартовыми днями или окном восстановления — не больше, чем в прошлой обычной неделе: окно восстановления — это лёгкие дни, добавлять в него пробежки — добавлять нагрузку. Рекомендация в форму — наибольшее число за недели до подводки.

- Выход: состав недели, число пробежек, недобор (кривая по нему уменьшает объём недели) и ограничения доступных доз по назначениям. Они не пересчитывают прогноз раздела 4.3.

### 4.6. Шаблон недели

- Вход: готовый состав и дозы раздела 4.5, число пробежек, допустимые дни, дата длинной, фиксированные занятия, метки календаря и восстановление после предыдущей недели. Назначения и форматы уже выбраны; шаблон только размещает их.
- **Дней бега** **[практ.]**: уровень 0 — до 5, уровни 1–2 — до 6, уровень 3 — до 7. Это верхняя граница, не формула числа дней; заданное вручную число пробежек поднимает границу до этого числа (не более 7 дней, остальное — вторые пробежки): выбор пользователя приоритетнее **[практ.]**. При наличии ограничений пользователя учитывается пересечение с доступными днями; без таких ограничений доступны все дни. Число пробежек и число занятых дней различаются при двойных.
- **Состав:** мультимножество конкретных тренировок, а не число взаимозаменяемых Q. Для каждой известны назначение, полная и рабочая длительности, интенсивность, восстановление, возможность совмещения и фиксированная дата, если она есть. E и R также имеют рассчитанные дозы; вторая пробежка входит в число и минуты заранее.
- **Выбор:** все допустимые размещения данного состава → отсев по обязательным ограничениям → однозначное ранжирование оставшихся → готовый шаблон. Ни дозы, ни типы занятий при размещении не меняются. Каталог и порядок выбора — 3.6.
- Гонка, тест, предстартовые дни и настройка входят во входной состав. Тест на дне длинной заменяет её; дополнительные длинные поверх бюджета не назначаются. Правила восстановления действуют и через границу недель.
- Если размещения нет, возвращается причина: какие занятия, даты или интервалы несовместимы. Раздел 4.5 меняет состав в порядке, заданном в разделе 4.5.10 и выбирает шаблон для него. Сам шаблон не превращает Q в E, не объединяет M с T и не снимает поддерживающую работу.
- Кросс и силовые размещаются вместе с бегом с учётом заданных ограничений (5.6), до окончательного выбора недели. Выход — дни и порядок занятий, число дней бега и вторых пробежек, причины выбора либо невозможности размещения.

### 4.7. Заполнение

- Вход: выбранное размещение (раздел 4.6), состав и дозы (раздел 4.5). Здесь только запись: минуты, разминки, ускорения и округление уже рассчитаны в разделе 4.5; новые занятия, интенсивные отрезки и пересчёт минут не выполняются.
- Каждый день получает готовую тренировку своего занятия из состава. Сумма недели = минуты кривой раздела 4.4 (кривая уже уменьшена до вмещающегося, раздел 4.5.9.5) с учётом перебора до 10 мин из раздела 4.5.8; исключение — неполная неделя 1.
- Выход: тренировки по дням.

### 4.8. Контроль нагрузки

- ACWR каждой недели до подводки — по тренировкам собранной недели (TRIMP Эдвардса, пятизонный, кросс — по классу). Проверка выполняется внутри подбора недели раздела 4.4, после её заполнения в разделе 4.7; только затем неделя принимается. Неделя со стартом может быть выше 1,3: нагрузку самой гонки не убрать.

### 4.9. Оформление

- Питание.
- Запись: зоны 1–2, включая разминки и заминки, — по времени, кратно 5 мин; зоны 3–5 — по темпу, отрезки в целых минутах; МПК и повторы — по дистанции.
- Км недель — по элементам тренировок; итоги и примечания.

## 5. Детальные правила алгоритма

Здесь приведены формулы, ограничения и источники для алгоритма из раздела 4.

### 5.1. Текущая форма

#### 5.1.1. Расчёт текущей формы

- **VDOT** — по Дэниелсу–Гилберту ([формулы](https://notes.billmill.org/fitness/calculating_v02_max.html): в источнике приведены по Omni Calculator как совпадающие с Дэниелсом; имя Гилберта на странице не названо): `VO2 = −4,60 + 0,182258·v + 0,000104·v²` (v — м/мин); доля VO2max от длительности `f(t) = 0,8 + 0,1894393·e^(−0,012778·t) + 0,2989558·e^(−0,1932605·t)` (t — мин); `VDOT = VO2(v) / f(t)`.
- **Время на дистанции:** для эквивалента одного результата — решение уравнения VDOT; для индивидуального прогноза — профиль всех введённых результатов. Ультра — экстраполяция с отдельной пометкой неопределённости; марафонский VDOT по Тэнде не подменяет индивидуальный профиль.
- **Темп на заданной длительности** (`paceAtDuration`) и **при доле VO2max** (`paceAtPct`) — из той же физиологии.
- **VDOT по ПАНО:** темп ПАНО считается выдерживаемым 60 мин (порог Дэниелса). Если VDOT по ПАНО и по результатам расходятся больше чем на 2, выводится примечание.

#### 5.1.2. Профиль результатов [практ.]

- Хранить пары `(дистанция, время, VDOT)` всех введённых результатов; `Vbest = max(VDOT)` — верхняя граница, а не текущая форма на любой дистанции.
- Начальная модель: `ln(T) = a + b·ln(D)` — степенная форма [Riegel 1981](https://nku.edu/~longa/classes/mat375/docs/CrossCountry/riegel.pdf). По двум разным дистанциям `b = ln(T2/T1) / ln(D2/D1)`; по большему числу — линейная регрессия всех точек. Индивидуальный `b` оправдан: модель с `b`, оценённым по двум гонкам, точнее фиксированного `k = 1,07` (MSE 208 против 381, [Vickers & Vertosick 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5000509)). У Riegel `b` бегунов — 1,05–1,08; значение вне этого диапазона выводится с пометкой «экстраполяция ненадёжна». Ошибка 1% во времени одной из гонок меняет `b` и сдвигает оценку марафона примерно на 2% (следует из формулы). Степенная форма действует для 3,5–230 мин; при ожидаемом времени дольше 230 мин оценка помечается как оптимистичная (у Riegel кривая рекордов выше 230 мин загибается вверх). На каждой дистанции оценка VDOT ограничена `Vbest`. Это проектная модель экстраполяции, не установленная физиологическая зависимость.
- Повторные результаты одной дистанции не создают дополнительные точки профиля: использовать лучший из сопоставимых недавних результатов; исходные записи сохранять. Несопоставимость условий не исправлять выдуманными поправками.
- При одном результате профиль выносливости неизвестен: показывать эквивалент Дэниелса с этой оговоркой. Без результатов использовать ПАНО с той же оговоркой.

Зоны Дэниелса (Daniels' Running Formula; проценты и длительности отрезков — по [обзору](https://www.coachray.nz/2023/05/03/jack-daniels-running-intensity/)):

| Зона | Определение |
|---|---|
| E (лёгкий, длинная) | 59–74% VO2max |
| Восстановительный | медленная половина E (отдельной зоны у Дэниелса нет) |
| M (марафонский) | 75–84% VO2max; темп марафона при этом VDOT |
| T (порог) | 83–88% VO2max; темп, который держится ~60 мин в гонке |
| I (МПК) | 95–100% VO2max; отрезки 3–5 мин |
| R (повторы) | >100% VO2max, около темпа гонки на милю; отрезки ≤ 2 мин, отдых 2–3 × длительность отрезка |
| Ускорения | в темпе R |

Окна вокруг темпа — допуск для часов, доля темпа **[практ.]**: темп по GPS колеблется на 1–2% скорости, более узкое окно сбивало бы выполнение элементов тренировки; окно гоночных темпов сдвинуто в медленную сторону — начать быстрее цели дороже, чем медленнее:

| Темп | Окно |
|---|---|
| M, темп гонки, ПМ, темпы 5 и 10 км | −0,8% … +1,25% |
| T | ±1,6% |
| R, ускорения | ±1,25% |
| Ультра-темп в тренировке | −2,5% … +3,5% |
| Ультра на старте | −1,5% … +4,5% |

Если введён темп ПАНО, порог недели = ПАНО × T(w) / T(0), где T(w) — темп T по траектории формы недели w (5.3), T(0) — исходный.

- **Темп ПАНО в форме** подставляется из лучшего результата (порог Дэниелса), пока его не ввели вручную.
- Реализация: `bestVdot`, `vdot`, `paceSet`, `zonePaces`, `PW`, `win`.

### 5.2. Календарь

- **База** (`planBasics`): число недель N, недели подводки, B = N − недели подводки. Меньше 4 недель — ошибка.
- **Длительность по умолчанию [практ.]**, недель: чем длиннее дистанция, тем больше объём и длинная, которые нужно нарастить при ограничениях роста раздела 4.4; длительность и даты связаны:

| Дистанция | 5 км | 10 км | 21,1 | 42,2 | 60 | 80 | 100 | 120–160 |
|---|---|---|---|---|---|---|---|---|
| Недель | 8 | 10 | 12 | 16 | 18 | 20 | 22 | 24 |

- **До выбора фаз** рассчитываются уровень 80/20 и целевой пик по правилам 5.4.3. Для этого используются исходная форма раздела 4.1, текущий объём и тренировочная история; прогноз раздела 4.3 и собранные недели не требуются.
- **Фазы Дэниелса:**

| Фаза | Содержание |
|---|---|
| I | база: E + ускорения |
| II | повторы (R) |
| III | интервалы (I) |
| IV | порог и специфика дистанции |

  - Фаза I = round(B/4) при B ≥ 8 и выполненном хотя бы одном условии, иначе фазы I нет:
    - `exp` = novice: ткани и техника не готовы к интенсивной работе;
    - рост: целевой пик (5.4: по уровню 80/20 от текущего объёма или ручной) ≥ 2 × текущий объём **[практ.]**: при двукратном наборе объёма нагрузка на ткани растёт и без интенсивной работы; так построены Higdon Novice 1 (рост ×2,6) и Hansons Beginner (×3,6–4,0): первые 4–5 недель только лёгкий бег;
    - перерыв: текущий объём в км (минуты переводятся по `kmPerMin`) ≤ 50% `maxVolEver`, если он задан **[практ.]**: аэробная форма после перерыва возвращается быстрее, чем выдержка тканей.

Во всех остальных случаях качественные тренировки идут с первой недели (так построены готовые планы Higdon Intermediate/Advanced и Garmin при умеренном росте объёма). Остаток делится на три почти поровну: по round(остаток/3) на II и III, всё оставшееся — на IV.

  - Подводка — продолжение фазы IV.
- **Промежуточные старты:** старт, после которого восстановление не успевает закончиться до главного, убирается с примечанием. Лучше назначать промежуточный старт на тот же день недели, что и главный: ритм недели (длинная, качественные, отдых) не сбивается; при другом дне выводится примечание (даты не меняются). Контрольный тест (−21 день) всегда в этом дне.
- **Контрольный тест** (Дэниелс: VDOT уточняют по свежему старту) ставится, если выполнены все условия: не ультра; план от 8 недель; своего старта за 10–35 дней до главного нет; `autoTest` не выключен. Тест — 5 км (для целей до 10 км включительно) или 10 км, за 21 день до главного старта, в любой день недели: дата не подгоняется под шаблон, шаблон недели подбирается под дату.
- **Метки дней:** день старта, «за 1–2 дня до старта», «восстановление». Недавняя гонка до плана (`preCtx='race'`) тоже даёт окно восстановления.
- **Восстановление после старта — Дэниелс:** 1 лёгкий день на каждые 3 км гонки, округление к ближайшему целому ([Daniels' Running Formula](https://us.humankinetics.com/blogs/excerpt/sample-running-program-from-daniels-running-formula): 15 км — 5 дней, полумарафон — 7): 5 км — 2, 10 км — 3, полумарафон — 7, марафон — 14. В эталонах Garmin первая Q после 10 км и после полумарафона стоит на 3-й день (Daniels строже: 4-й и 8-й день), оставлено по Daniels. Для ультра — как после марафона (14 дней) **[практ.]**: правило выведено для дистанций до марафона, а по км окно ультра заняло бы всю подводку. В окне нет длинной и качественных. За 1 день до старта — лёгкий выезд, за 2 дня — отдых.

### 5.3. Прогноз и цель

- Прогноз рассчитывается по календарю из раздела 4.2 и используется при построении объёма в разделе 4.4. Вход — профиль раздела 4.1 и срок подготовки; выход — траектория формы по неделям и ориентир времени цели.
- **Прогноз — ориентир, а не точный расчёт.** В проверке на 156 бегунах формула Riegel (`k = 1,07`) дала время марафона на 10 и более минут быстрее фактического примерно у половины бегунов, лучшие модели (две гонки + километраж) — у четверти ([Vickers & Vertosick 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5000509)). Время показывается как ориентир с диапазоном; темпы тренировок подбираются под траекторию формы.
- **Исходная оценка** `V0(D)` — профиль 5.1 (степенная форма, [Riegel 1981](https://nku.edu/~longa/classes/mat375/docs/CrossCountry/riegel.pdf)).
- **Траектория роста [практ.].** Скорость на дистанции D растёт не быстрее `r` в неделю и не выше скорости, соответствующей `Vbest` на этой дистанции: `v(D, w) = min(v0(D)·(1 + r)^w, v_Vbest(D))`; `V(D, w)` — VDOT по `v(D, w)`.
  - `r = 0,4%` в неделю — принятый темп улучшения **[практ.]**: в 8-недельном блоке у любителей со стажем 4+ лет скорость на 2 км выросла на 3,0–3,5% ([Festa 2020](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2019.00070/full)). У хорошо подготовленных бегунов (VO₂peak 68 мл/кг/мин) за 16 недель улучшение 5 км составило 0,6–1,5%, большая часть изменений ниже порога обнаружения ([Filipas 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9299127)): с ростом уровня реальный темп ниже. Перенос одного 8-недельного блока на весь срок — допущение.
  - Лучший результат сам не растёт: расти может только дистанция, на которой форма ниже `Vbest` (дефицит выносливости). Рост общей верхней границы формы — отдельный механизм, модели для него нет.
- **Акцент и темпы — из одной траектории.** Дистанции с наибольшим разрывом `w(D)` до `Vbest` (в неделях роста, 5.5) определяют акцент развивающих доз; та же траектория задаёт темпы T, I, R и M по неделям. Другие данные в план не вводятся.
- **Ручная цель сдвигает траекторию без деления на разрыв.** VDOT — единая мера формы, не зависящая от дистанции (Дэниелс), поэтому цель на одной дистанции означает рост формы на одну величину на всех. `Vц` — VDOT введённого времени цели (поправки трассы убраны); `Δ = Vц − V(Dц, B)`.
  - `Δ ≥ 0` (цель быстрее ориентира или равна ему): `V_ручн(D, w) = V(D, w) + Δ·min(w, B) / B` для всех дистанций и недель.
  - `Δ < 0` (цель медленнее ориентира): уменьшается скорость роста — `r'` из диапазона [0; `r`] подбирается так, чтобы `V(Dц, B)` при `r'` равнялось `Vц` (деление пополам); `V_ручн(D, w) = V(D, w)` с `r'` вместо `r` на всех дистанциях. Если `Vц ≤ V0(Dц)`, `r' = 0`: рост не планируется, план строится от текущей формы.
  - Траектория не убывает при любом знаке `Δ`; в конце рабочих недель на `Dц` получается ровно `Vц` (кроме `Vц ≤ V0(Dц)`: там намеренно остаётся текущая форма). Темпы пересчитываются из `V_ручн`. Если `Vц` выше `Vbest`, выводится предупреждение «вне диапазона модели 1», план строится; верхняя граница `Vbest` сдвигается вместе с траекторией.
- **Темпы:** каждый тип берётся из `V(D, w)` на дистанции или длительности, где он по определению Дэниелса нагружает так же, как гонка: T — 60 мин; I — 11 мин (по формуле `f(11) = 1,00`, т. е. 100% VO2max); R — миля (1609 м); M, ПМ-темп, темп 10 и 5 км — их дистанции; специфическая работа и ультра-темп — `V(Dц, w)`. Рост формы идёт только в рабочие недели B: подводка прироста не добавляет, поэтому в `Δ` стоит `V(Dц, B)`. При одном результате `V0(D)` на всех дистанциях равна `Vbest`, траектория плоская, форма по умолчанию не растёт; рост задаёт только введённая цель.
- **Цель по умолчанию** — конец траектории на целевой дистанции с поправками трассы; диапазон — от исходной оценки `V0(Dц)` до верхней границы `Vbest`. Если исходная оценка дольше 230 мин, она помечается как оптимистичная.
- **Порядок:** прогноз → цель → объём → дозы и форматы. Нехватка бюджета сообщается как ограничение состава, без пересчёта траектории.
- **Поправки трассы** (`courseAdjust`) сохраняются: жара +3%, высота +0,8% на 300 м выше 300 м (до 10%), набор +0,6 с/м (до 35% времени) **[практ.]**; меняют время старта, не форму. Что известно из источников: жара — эффект растёт с WBGT и зависит от уровня бегуна (марафон Нью-Йорка, рост WBGT с +8 до +20 °C: от 5% до 22% по группам, [Gasparetto & Nesseler 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7350124)), поэтому плоские +3% — упрощение; высота — VO2max падает на 6,3% на 1000 м (4,6–7,5%, от 300 до 2800 м; [Wehrlin & Hallén 2006](https://doi.org/10.1007/s00421-005-0081-9)), на реальных стартах времена хуже на 2–4% ([сводка](https://sport-calculator.com/blog/how-altitude-affects-running)); +0,8% на 300 м (≈2,7% на 1000 м) по порядку согласуется; набор — стоимость бега от уклона `Cr(i) = 155,4i⁵ − 30,4i⁴ − 43,3i³ + 46,3i² + 19,5i + 3,6` Дж/кг/м, i — доля ([Minetti 2002](https://iris.unibs.it/retrieve/ddc633e4-3c03-4e2e-e053-3705fe0a4c80/Minetti%20JAP%202002.pdf)); константа 0,6 с/м из неё не выведена; вторичные правила дают 1,5–2,4 с на метр набора без учёта спусков ([Go&Race](https://goandrace.com/en/calculate-equivalent-running-speed-on-a-hilly-course.php)) — источники расходятся, а поправка меняет только показываемое время. Горки выбираются с учётом рельефа и назначения блока.
- В форме: введённые результаты и их VDOT, профиль на целевую дистанцию, верхняя граница, ориентир и диапазон времени цели, столбец «Под вашу цель».
- Затрагиваемая реализация: `bestVdot`, `forecastVd`, `trainingVdots`, `goalVerdict`, `forecastFor`, `buildPlan`.

### 5.4. Объём и зоны

#### 5.4.1. Распределение интенсивности

**Одна модель зон — пятизонная шкала пульса** (доли ПАНО — раздел 5.9). Каждая тренировка и каждый её элемент относятся к одной конкретной зоне:

| Зона | Что |
|---|---|
| Z1 | восстановительный бег, отдых между отрезками, заминка; длинная дольше 150 мин |
| Z2 | лёгкий, длинная до 150 мин, разминка |
| Z3 | M, steady, M в длинной |
| Z4 | T, темп полумарафона, T в длинной |
| Z5 | I, R, горки (по усилию), ускорения |

Темп 5–10 км (элементы и тренировки «темп гонки») — в зоне по границе Z4/Z5, как любой элемент тренировки с целью-темпом: быстрее границы — Z5, медленнее — Z4. Как правило темп 5 км — Z5, темп 10 км — Z4.

Элемент тренировки с целью-пульсом — в своей зоне; элемент тренировки с целью-темпом — по темпам Дэниелса недели. Границы: Z2/Z3 — посередине между быстрым концом E и M (ближе к VT1); Z3/Z4 — посередине между M и T; Z4/Z5 — посередине между T и I.

**Доли модели.** Исследования используют три зоны с границами VT1/VT2. В пятизонной шкале граница Z2/Z3 лежит у VT1, а Z4 центрирована на темпе T (порог). T — темп, который держат около часа, поэтому он не выше VT2 **[практ.]**: второй вентиляторный порог (RCT) у подготовленных бегунов — 84 ± 6% максимальной скорости, бег на 86% (на 2 SE выше RCT) выдерживали около 18,5 мин ([Condello et al. 2014](https://www.jssm.org/jssm-13-309.xml-abst)); прямого сопоставления с темпом T в источнике нет. Работа в Z4 — «между порогами»: пульс у темпа T держится около порога, а не выше. Поэтому зона 1 исследований = Z1+Z2; зона 2 (между VT1 и VT2) = Z3 + Z4 — **средняя** корзина; зона 3 (выше VT2) = Z5 — **верхняя** корзина. Минуты Z4 целиком расходуют среднюю цель. Эталоны согласуются: у Garmin Z3+Z4 — 17–21% минут (марафон 17, ПМ 18–20, 10 км 21) — столько же, сколько средняя корзина модели (`plans/sample/COMPARISON.md`, 3.1). Доли — ориентиры распределения и бюджеты интенсивности. Они не определяют назначение тренировки и не требуют добирать минуты любой работой той же зоны. Поддерживающие дозы учитываются за блок; его бюджет складывается из недельных бюджетов.

| Дистанция | Поляризованное, Z1+Z2 / средняя / верхняя | Пирамидальное | Источник |
|---|---|---|---|
| 5–10 км | 80/6/14 | 77/17/6 | [Filipas et al. 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9299127): плановые доли, табл. 1 (по факту, табл. 4: POL 80/6/14, PYR ≈ 78/15/7) |
| 21,1 км и длиннее | 82/8/10 | 75/22/3 | [Esteve-Lanao et al. 2026](https://doi.org/10.1177/17479541261468168): любители-марафонцы (авторы, журнал и DOI проверены, доли с полным текстом не сверены) |

- **Пул интенсивности.** Z1+Z2 в моделях — 75–82%, остальное — пул Z3–Z5 (18–25%). Тип и дозу работы в пуле выбирают фаза, акцент и лимиты Дэниелса (раздел 4.5); разбиение пула по зонам — ориентир.
- **Опыт.** Модели получены на подготовленных бегунах: пул Z3–Z5 умножается на kexp — novice 0,5; inter 0,75; adv 1 **[практ.]**; уменьшение уходит в Z1+Z2. Переносимость интенсивной работы растёт со стажем; готовые планы одного автора различаются так же: у Higdon Z3+Z4 на марафоне — 0% (Novice), 9–10% (Intermediate), 11% (Advanced); на полумарафоне 17% и 26%; на 10 км 7% и 19% (Intermediate и Advanced). У Hansons Beginner и Advanced доли одинаковы (марафон 82/17/2 и 82/16/2): различаются объём и частота.

**Расчёт акцента [практ.].** Используется профиль из раздела 4.1; акцент заново не определяется по целевой дистанции. Для каждой опорной дистанции D берётся дефицит в рабочих неделях:

\[
w(D)=\max\left(0,\frac{\ln\left(v_{best}(D)/v_0(D)\right)}{\ln(1+r)}\right).
\]

Здесь \(v_0(D)\) — текущая скорость по индивидуальному профилю; \(v_{best}(D)\) — скорость на D, соответствующая лучшему VDOT; \(r\) — недельный темп роста скорости из раздела 5.3. Набор опорных дистанций — раздел 5.5.1. Обозначение \(w(D)\) совпадает с разделом 5.5.1.

Пусть \(D_{best}\) — дистанция лучшего результата. Дефициты выносливости и скорости:

\[
w_E=\max_{D>D_{best}}w(D),\qquad
w_S=\max_{D<D_{best}}w(D).
\]

Для пустой группы максимум равен 0. При равном лучшем VDOT нескольких результатов границы групп — самая длинная и самая короткая дистанции этих результатов соответственно; дистанции между ними не определяют сторону акцента.

Направление и выраженность акцента нормируются на число рабочих недель B:

\[
a=\operatorname{clip}\left(\frac{w_E-w_S}{B},-1,1\right),\qquad
x_{rec}=\frac{1+a}{2}.
\]

\(\operatorname{clip}(y,l,u)=\min(u,\max(l,y))\). Значение \(a>0\) означает акцент на выносливость, \(a<0\) — на скорость; \(x=0\) соответствует поляризованной модели, \(x=1\) — пирамидальной. Дефицит, сопоставимый со всем сроком подготовки, даёт предельное смещение. Нормирование на B и линейное соответствие акцента положению ползунка — допущения калькулятора, а не результаты приведённых исследований.

Если профиль неизвестен либо оба дефицита меньше 1 рабочей недели, используется исходное распределение по дистанции: \(x_{rec}=0\) до 10 км включительно, \(x_{rec}=1\) для более длинных дистанций. При равных выраженных дефицитах \(x_{rec}=0{,}5\); оба направления требуют развития. Пользователь может изменить рекомендованное положение.

**Диапазон смещения бюджета типов.** Для одной и той же недели в совместном расчёте с разделом 5.5 определить два исходных бюджета: \(b_t^{POL}\) и \(b_t^{PYR}\) минут работы типа t. Оба используют одинаковые объём, фазу, историю прогрессии и поддерживающие дозы; различаются распределением интенсивности из таблицы моделей. Дополнительное смещение по акценту к этим исходным бюджетам ещё не применяется.

Тип учитывается по назначению работы, а не только по зоне: длинная и специфическая выносливость, T, M, I, R, горки и остальные предусмотренные назначения. Минуты составной тренировки учитываются по её частям без повторного счёта; разминки, заминки и паузы входят в соответствующую лёгкую работу.

Для положения ползунка x:

\[
b_t(x)=(1-x)b_t^{POL}+x b_t^{PYR},\qquad 0\le x\le1.
\]

Таким образом, диапазон смещения каждого типа ограничен его бюджетами в двух моделях. Доли зон из таблицы сами по себе не задают эти бюджеты: исходные бюджеты типов рассчитываются по назначениям и протоколам раздела 5.5. Одинаковые минуты одной зоны не делают типы взаимозаменяемыми.

Допустимое множество положений ползунка:

\[
X=\{x\in[0,1]:\ b_t^{min}\le b_t(x)\le b_t^{max}\ \text{для всех }t,\ \text{состав можно разместить}\}.
\]

\(b_t^{min}\) — обязательная доза типа с учётом поддержания за блок; \(b_t^{max}\) — предел по фазе, методическим лимитам, прогрессии и оставшемуся бюджету. Фиксированные занятия входят в бюджет первыми. При проверке размещения учитываются качественные дни и восстановление. Дискретные форматы могут давать разрывы в X, поэтому одного интервала между минимальным и максимальным значениями недостаточно.

Использовать выбранное пользователем положение, а без ручного изменения — \(x_{rec}\). Если оно недопустимо, выбрать ближайшее допустимое:

\[
x_{final}=\underset{x\in X}{\operatorname{argmin}}\,|x-x_{selected}|.
\]

При равном расстоянии выбрать положение ближе к \(x_{rec}\), затем меньшее x. При пустом X вернуть конкретный конфликт ограничений в совместный подбор состава; обязательные дозы и методические лимиты автоматически не уменьшать.

Поправка на опыт применяется к исходным бюджетам до смещения, один раз. В фазе I развивающий бюджет Z3–Z5 равен нулю; предусмотренные ускорения учитываются отдельно, ползунок эту фазу не меняет. После выбора форматов фактические доли Z1–Z5 считаются по тренировкам. Поддерживающие дозы сохраняются за блок, а полностью заполнять бюджет любой работой той же зоны не требуется.

- **Длинная:** до 150 мин включительно — Z2, дольше 150 мин (ультра) — Z1, потому что верх Z2 на такой длительности недостижим.

#### 5.4.2. Пересчёт минут в километры

- Темп каждой зоны:
  - Z1+Z2 — середина E;
  - средняя корзина (Z3 + Z4) — T; у марафона среднее T и M, у полумарафона — среднее T и темпа полумарафона, у ультра — среднее T и ультра-темпа;
  - верхняя корзина (Z5) — I.
- Км за минуту = Σ (доля корзины × 60 / темп корзины). Это `kmPerMin`.
- В фазе I берётся распределение [1, 0, 0] (всё Z1+Z2).
- Км в плане считаются по элементам тренировок. Если цель элемента тренировки задана пульсом, берётся средний темп этой зоны на текущей неделе. У бега в гору есть подсказка темпа `pk` — она нужна только для оценки км и в Garmin не уходит.

- Уровень — наивысший, чей средний объём не больше текущего: бегун выбирает план по объёму, который уже выдерживает. Объём, введённый в км, переводится в часы по `kmPerMin` при текущей форме и распределении по умолчанию для целевой дистанции (принцип 2.3); обратно в км — так же.
- **Пик по объёму бегуна — линейно между уровнями [практ.].** Пик — функция текущего объёма, а не ступенька: при среднем уровня k ≤ текущем объёме < среднего уровня k+1
  - пик = пик_k + (текущий − среднее_k) / (среднее_{k+1} − среднее_k) · (пик_{k+1} − пик_k);
  - на среднем объёме уровня пик равен табличному;
  - **выше среднего верхнего уровня** кривая масштабируется по объёму бегуна: пик = текущий · пик₃ / среднее₃ (отношение пик/среднее верхнего уровня). **Ниже уровня 0** пик — пик уровня 0, кривая растёт от текущего объёма в пределах ограничений раздела 4.4;
  - пик всегда выше текущего объёма, правила «текущий + прибавка» нет: пик не зависит ни от числа пробежек плана, ни от числа пробежек уровня;
  - причина: таблица — готовые планы, а не функция объёма; по номеру уровня пик менялся скачком на границе (марафон: 6:59 ч → 7,75 ч, 7:00 ч → 9 ч). Сглаживание в источнике не задано;
  - по номеру уровня остаётся ступенчатым потолок дней бега (`dayCap`).
- Если текущий объём ниже уровня 0, план растёт от текущего объёма; выводится примечание.
- Ультра 60–160 км — уровни 50 км **[практ.]**: в источнике уровни заданы для 50 км; на более длинных ультра растёт длительность длинной (потолок `ultraLong`, раздел 5.5), а не недельный объём — его ограничивают правила роста раздела 4.4.
- **Пик в форме** — пик построенного плана (достижимый с учётом всех ограничений раздела 4.4). Ручной пик выше достижимого подсвечивается.

#### 5.4.4. Объём под цель и Тэнда

- Исходный объём и пик — по уровню 80/20 и тренировочной истории; цель задаёт назначение подготовки. Рост и вместимость ограничивают допустимые дозы до составления тренировок.
- Тэнда ([Tanda 2011](https://www.redalyc.org/pdf/3010/301023457005.pdf)): `Pm = 17,1 + 140·exp(−0,0053·K) + 0,55·P`, где Pm и P — с/км, K — средние км/нед, P — средний тренировочный темп за 8 недель до старта. Выборка: 22 бегуна (21 мужчина), 46 марафонов, 2:47–3:36; ошибка около 4 мин (69% прогнозов) относится к этой выборке.
- Оценка рассчитывается после сборки плана и выводится в итогах (5.9.2). Модель — диагностическая оценка связи объёма, среднего темпа и результата, только в пределах выборки (ориентир 2:47–3:36). Вне диапазона оценка не выводится. Обратная регрессия не задаёт дозу.
- Оценка Тэнды не меняет прогноз, цель, темпы и объём.
- Зависимость необходимого объёма от цели не обоснована и не откалибрована, поэтому объём от цели не зависит.

#### 5.4.5. Рост, разгрузки и подводка

- **Ограничения роста:** ACWR ≤ 1,3 (раздел 5.8) и беговые км ≤ 1,3 × км опорной недели i−2 (Nielsen et al. 2014). В правило двух недель кросс не входит: в источнике мерили беговую дистанцию. ACWR учитывает интенсивность и кросс, правило двух недель — беговой объём, по которому мерили травмы; поэтому действуют оба. Оба проверяются по собранной неделе (раздел 4.4, построение по неделям), поэтому округление пробежек до 5 мин и минимум 30 мин уже учтены. Недельные ограничения — страховка, не предиктор: в Frandsen et al. 2025 (5205 бегунов, BJSM) с травмами связаны скачки дистанции одной пробежки, а ACWR и недельное изменение — нет (у ACWR связь обратная, возможно из-за обратной причинности), поэтому рост длинной и число пробежек ограничены отдельно (раздел 4.5, «Длинная» и «Число пробежек»).
- **История до плана** для правила двух недель — текущий объём в км (или перевод минут в км); при переходе с другой программы неделей не раньше чем 1 неделю назад — её пиковая неделя.
- **Режимы недель Б** (`deload`; состав недели Б и откат длинной А — раздел 4.4.4):
  - `need` — неделя Б после 4 недель роста, пока объём растёт (ниже 99% пика), и не в последние 4 недели перед подводкой (Garmin, марафон: недели 5, 9, 13);
  - `w31` — каждая 4-я неделя, кроме последней недели перед подводкой;
  - `none` — без недель Б (Hansons); откат длинной А действует во всех режимах.

  Неделя промежуточного старта или теста сама служит неделей Б (Пфитцингер, Advanced Marathoning: 45→37 и 54→43 — это −18% и −20%): отдельная неделя Б в неё не ставится, счёт недель роста до следующей недели Б начинается заново.

- **Подводка** — доли пикового объёма, **считаются по дням от старта, а не по календарным неделям**: блок k — дни 7k…7k+6 до старта (день старта входит в первый блок), доли блоков — как ниже (ближайший к старту — последний). Доля календарной недели = среднее по её дням до старта; при старте в воскресенье это целые недели (как ниже), в другие дни неделя смешанная (пример: 10 км, старт в понедельник — 90% и 47% пика, сама неделя старта — только гонка). Неделя старта получает минуты без самой гонки: доля за её дни до гонки (вс — 6 из 6). Подводящими считаются все недели с долей меньше 100%. Марафон и ультра — 3 недели: 72 / 58 / 22% пика; остальные — 2 недели: 88 / 40% (обоснование и эталоны — раздел 4.4.6). Последний блок — основная подводка, предыдущие — предварительная подводка; он же последняя неделя Б. Пик для подводки — пик кривой без неполной недели 1; если рабочих недель нет (весь план — подводка, например ультра на 4 недели со стартом в понедельник), берётся текущий объём. Неделя старта — как и остальные: кривая строится с её учётом. Неделя вмещает предстартовый выезд, настройку и лёгкие (не короче 30 мин, не длиннее лёгких подводящих недель, по 5 мин), поэтому её объём в кривой = то, что вмещает собранная неделя (без самой гонки); если он отличается от доли подводки больше чем на 2% — примечание.
- **Неполная неделя 1:** кривая считает её полный объём; ставится доля по числу дней, нагрузка для ACWR смешивается с историей пропорционально дням; рост дальше идёт от текущего объёма.
- Реализация: `planBasics`, `runPass`, `levelFor`, `tidShares`, `kmPerMin`, `tandaK`, `tandaPace`.

### 5.5. Состав недели

#### 5.5.1. Назначения, дозы и выбор протокола

| Назначение | Основные параметры дозы |
|---|---|
| Аэробная выносливость | Частота и полная длительность лёгкой работы |
| Устойчивость к длительной работе | Длительность длинной, интенсивная часть и накопленная усталость |
| Пороговая способность | Рабочие минуты T, длина отрезков, темп и паузы |
| Аэробная мощность | Рабочие минуты I, длина отрезков, темп и восстановление |
| Экономичность и скорость | Короткие повторы, ускорения и горки с подходящим восстановлением |

- Дистанция и профиль результатов задают необходимые качества и акцент развития. Протоколы исследований перенесены на бегуна допущением: выборки (уровень, дистанция) могут отличаться **[практ.]**.
- **Акцент — по форме профиля результатов** (логика без отдельных источников): разрыв на дистанции D — `w(D) = ln(v_Vbest(D) / v0(D)) / ln(1 + r)` недель до `Vbest` (5.3); дистанции — опорные дистанции темпов типов (5.3: миля, дистанция I за 11 мин, дистанция T за 60 мин, M, ПМ, 10 и 5 км) и `Dц`. Дистанции длиннее дистанции лучшего результата с `w > 0` — западает выносливость: акцент на длинную, T и M; короче — западает скорость: акцент на I, R и горки; выбирается сторона с наибольшим `w`. Разрыва нет, если наибольший `w` меньше 1 недели — акцент по дистанции цели и фазе Дэниелса (таблица типов ниже). Происхождение правила: разрыв между скоростью и выносливостью в исходном профиле — что западает, то тренируется больше, и чем больше разрыв, тем дольше и сильнее акцент; остальные качества не исключаются, иначе разрыв уйдёт в другую сторону. Без разрыва — стандартная программа (слоты Дэниелса по фазам, ниже). Акцент длится наибольшие `w` недель (пока на траектории (5.3) скорость не дошла до `v_Vbest(D)`), затем возвращается стандартная программа. В неделе слот Q получает то качество, у которого поддерживающий стимул не должен прерваться (последний стимул на 1 неделю меньше допустимого интервала качества назад); остальные слоты и длинная идут на акцент; при равенстве претендентов — порядок стандартной программы фазы.
- Развивающие дозы в исследованиях не установлены: дозой служит ступень лестницы форматов (ниже), порядок ступеней — по объёму работы **[практ.]**. Поддерживающая граница задана ниже.
- **Поддерживающая доза — граница вытеснения, а не цель.** Остальные качества доводятся до своих границ, весь остаток бюджета идёт на акцент; ниже границы акцент их вытеснять не может. Граница **[практ.]**: работа качества не ниже доли `f` опорной дозы (последняя развивающая того же назначения, тот же темп): `f` = 1/3 для аэробной мощности, порога, скорости и экономичности; `f` = 2/3 для устойчивости к длительной работе (длинная, M, ультра-темп): при сокращении сессии с 40 до 13 мин VO2max и короткая выносливость сохранились, а длительная (2 ч и более) упала примерно на 10%, при 26 мин — нет ([Hickson et al. 1982](https://pubmed.ncbi.nlm.nih.gov/6214534/)). Основание для 1/3: выносливость сохраняется до 15 недель, если при сохранённой интенсивности объём снижен на 33–66% (в исследованиях — до 13–26 мин за сессию) или частота снижена до 2 сессий в неделю ([Spiering 2021](https://pubmed.ncbi.nlm.nih.gov/33629972/)); сочетание обоих снижений в аннотации не заявлено, поэтому они не складываются: при интервале n недель между стимулами доза не ниже n·`f` опорной, но не выше опорной, поэтому допустимо только n ≤ 1/`f`: для `f` = 1/3 — n = 1…3 (раз в неделю 1/3, раз в 2 недели 2/3, раз в 3 недели полная; пример: 30 мин T — 10 мин еженедельно, 20 мин раз в 2 недели или 30 мин раз в 3 недели; 10 мин раз в 3 недели не допускается); для `f` = 2/3 — только еженедельно, доза не ниже 2/3. Равенство среднего объёма разных режимов — допущение проекта: исследования снижали длительность при сохранённой частоте и частоту при сохранённой длительности по отдельности. Интервал не больше 3 недель и не больше 1/`f` **[практ.]**: у подготовленных бегунов VO₂max быстро падает при перерыве менее 4 недель ([Mujika & Padilla 2000](https://pubmed.ncbi.nlm.nih.gov/10966148/)). Сумма доз ограничена недельными бюджетами, слотами Q и восстановлением. Поддержание может чередоваться между неделями; постоянно исключать качество из-за чужого дефицита нельзя.
- **Свободный слот качественных [практ.].** После поддерживающих доз и дозы акцента слот получает тип, у которого достижимый остаток больше: остаток корзины (Z3 и Z4 — средняя, Z5 — верхняя), не больше лимита Дэниелса на одну тренировку этого типа (иначе R с лимитом ≈ 9 мин занимал слот при остатке верхней корзины 40+ мин, а порог оставался без слота); при равном остатке — тип, ещё не стоявший в неделе, затем по давности. Тип, уже стоящий в неделе, повторяется дозой прошлой ступени (повторение разрешено, 4.5.5); R, горки и длинная со вставками — не чаще раза в неделю. Причина: «весь остаток бюджета идёт на акцент», а одна ступень лестницы в неделю расходует 15–25 мин при остатке цели 60–130 мин (случайные вводные, inter: доза равнялась следующей ступени в 82–99% случаев). Следствие в вычислении: бюджет не добирается лестницей, поэтому слот не уходит на маленькую дозу той же корзины, пока остаток есть.
- Если минимальные поддерживающие дозы не помещаются, выбирается допустимое чередование в пределах допустимого интервала качества (n ≤ 1/`f`, не больше 3 недель). Если и оно невозможно, указывается конкретная нехватка бюджета; границу дозы и бюджет не меняют, неделю пропускает качество с наибольшим запасом до предела интервала (раздел 4.5.10).
- Состояние прогрессии хранится по назначению: предыдущие полная и рабочая длительности, темп, отрезки, паузы, дата поддерживающего стимула и следующий предусмотренный переход.
- Тест или гонка заранее расходуют бюджет и учитываются по своим стимулам; дополнительная длинная поверх них не добавляется автоматически.

Основания выбора:

- [Filipas et al., 2022](https://onlinelibrary.wiley.com/doi/full/10.1111/sms.14101): повторяемые блоки и изменение распределения интенсивности; исследование не задаёт универсальную лестницу всех тренировок.
- [Hov et al., 2023](https://pubmed.ncbi.nlm.nih.gov/36314990/): разные интервальные протоколы дают разный эффект на аэробную мощность; одинаковая категория «интенсивная работа» не делает их взаимозаменяемыми.
- [Seiler & Hetlelid, 2005](https://pubmed.ncbi.nlm.nih.gov/16177614/): паузы влияют на доступную интенсивность и физиологический ответ; рабочие минуты не являются полной характеристикой дозы.
- Правила резервирования поддержки и выбора переходов выше — проектные **[практ.]**: нужны все необходимые стимулы при ограниченной нагрузке.

#### 5.5.2. Лимиты Дэниелса

Источник: [обзор Дэниелса](https://www.coachray.nz/2023/05/03/jack-daniels-running-intensity/) подтверждает T ≤ 10%, I ≤ 8%, R ≤ 5% км недели, M < 20% и ≤ 110 мин, длинная ≤ 150 мин (кроме ультра) **[метод.]**. Пределы 10 км (I) и 8 км (R), доля длинной 25–30% и граница 64 км в обзоре не найдены — они из книги ([Daniels' Running Formula](https://us.humankinetics.com/products/daniels-running-formula-4th-edition)), по тексту не сверены.

- **Длинная:** не больше 30% недельного километража при объёме < 64 км (40 миль), иначе не больше 25% (с поправкой на частоту — ниже); не больше 150 мин (кроме ультра). Доля считается по км, как у Дэниелса: км длинной ≤ доля × км недели (км недели — по распределению зон и темпам недели); в минуты переводится по темпу длинной (середина E). Длинная медленнее среднего темпа недели, поэтому по минутам её доля больше, чем по км. Доля 40% (марафон и ультра) — тоже от км недели. У длинной со вставками км считаются с темпом вставок.
- **За одну тренировку** — в км недели, переведённых в минуты работы в темпе типа:
  - T, T в длинной, темп 10 км — ≤ 10%. Темп 10 км отнесён к T **[практ.]**: в эталонных планах 15 из 26 его тренировок выше 8%·k (медиана 1,15), под лимит I они не помещаются; абсолютного предела 10 км, как у I, нет;
  - I и интервалы в темпе 5 км — ≤ 8% и ≤ 10 км;
  - R — ≤ 5% и ≤ 8 км;
  - M, темп полумарафона, steady, M в длинной, ультра-темп — ≤ 20% и ≤ 110 мин. Темп полумарафона отнесён к классу M **[практ.]**: он медленнее T, лимита на него в источнике нет, а лестница ПМ (до 60 мин работы, ≈ 12 км) при 10% достижима только от 120 км в неделю.
- **Поправка на частоту [практ.].** Процентные лимиты Дэниелса заданы для бега 6–7 раз в неделю. При меньшем числе пробежек n (привычное число по 5.5, «Число пробежек», либо `runs` при ручном вводе; в плане фиксировано) тот же объём делится на меньшее число тренировок, и каждая занимает большую долю недели. Поэтому при n < 6 процентные лимиты умножаются на k = 6/n: длинная ≤ min(40%, доля · k), T и темп 10 км ≤ 10% · k, I и темп 5 км ≤ 8% · k, R ≤ 5% · k, M, темп полумарафона, steady и ультра-темп ≤ 20% · k. Абсолютные пределы не меняются: длинная ≤ 150 мин, I ≤ 10 км, R ≤ 8 км, M ≤ 110 мин; для марафона и ультра доля длинной остаётся 40%. Пример: n = 4 — длинная до 40% км недели, T до 15%. Готовые планы на 4–5 пробежек (Garmin, Higdon) ставят длинную в 33–44% минут недели.
- **Горки** — ≤ 20 мин работы и не больше лимита T **[практ.]**: подъёмы по усилию RPE 8/10 — короткая работа в Z5, по объёму она ближе к R, чем к темповой.
- **Ультра** — длинная до 40% недели. Потолок длинной `ultraLong` — по ориентирам тренеров ([Marathon Handbook](https://marathonhandbook.com/ultramarathon-long-runs/), вторичный источник): 50 км — 4 ч (опытным 5 ч); 50 миль и 100 км — до 6 ч (или два дня подряд по 25–30 миль); 100 миль — 50 миль (80 км) или два бега по 5–6 ч. Опорные значения потолка: 50 км — 300 мин, от 80 км — 360 мин; между ними линейно **[практ.]**. Длинная тренирует время на ногах и жировой обмен.

Минимальная работа за тренировку **[практ.]**, мин — меньше этого стимул типа не набирается (одна-две короткие ступени — это разминка, а не тренировка):

| Тип | T | Порог в горку | I | R | M | Steady | Темп полумарафона | Темп 10 км | Темп 5 км | Горки | Ультра-темп | Вставки в длинной |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Мин. работа | 10 | 12 | 6 | 4 | 15 | 30 | 10 | 10 | 6 | 6 | 15 | 10 |

#### 5.5.3. Типы качественных по фазе и дистанции

| Дистанция | II | III | IV |
|---|---|---|---|
| 5–10 км | R, T, порог в горку, горки | I, T, порог в горку | темп гонки, T, R |
| 21,1 км | T, порог в горку, R, горки | T, порог в горку, I | темп полумарафона, T, I, steady |
| 42,2 км | T, порог в горку, R, горки | T в длинной, T, порог в горку, I | M в длинной, T, M, steady |
| Ультра | T, горки | ультра-темп, T | ультра-темп, целевой темп в длинной, T |

- **Слоты Q по фазам Дэниелса** (пересказ плана 5–10 км, [обзор](https://runningwithrock.com/review-jack-daniels-5k-10k-training-plan/); недельной прогрессии источник не даёт): фаза II — Q1 R, Q2 T, Q3 длинная; фаза III — Q1 I, Q2 T (с небольшим набором R), Q3 длинная; фаза IV — до трёх Q, в неделю гонки основную Q сокращают, вторую снимают, длинная лёгкая. Длинная здесь — Q3, поэтому при бюджете 2Q (раздел 4.5.3) отдельных Q две.
- Порядок типов в дне Q: назначение блока → поддерживающая/развивающая доза → следующий допустимый формат выбранного протокола → размещение. История учитывается по назначению, а не только по типу T/I/R.
- Steady: непрерывно, темп от M до середины между M и T (зона Z3), 30–90 мин (ступени 30, 40, 50, 60, 75, 90′), берёт среднюю цель; лимит как у M. **Только в блоке специфики (фаза IV)** — специфика марафона и, реже, полумарафона; раньше фазы IV его нет. В неделе фазы IV марафонская работа набирается любым сочетанием: M во вставках длинной и steady/МР-бег в неделе, а если вставок в длинной нет (откат А, неделя Б, короткая длинная) — steady или МР-бегом. Блок специфики короткий, а база уже есть, поэтому первая доза steady и M без истории — наибольшая ступень в пределах бюджета недели (иначе за 4 недели блока лестница доходит лишь до 40–50 мин; в эталонах Z3 в последние 6 недель до подводки — Higdon 9–11%, Garmin 8%, при расчёте с лестницей от 30′ — 4–7%).
- **Порог в горку [практ.]:** подъёмы по усилию порога (пульс Z4), вниз трусцой столько же; ступени 3×4′, 3×6′, 3×8′, 4×6′, 4×8′; средняя цель, лимит и минимум — как у T (минимум 12 мин). Ставится **в дополнение** к T и I, не вместо: у Garmin «Горки» — 20 из 156 Q-сессий, 3×4′…3×8′ в Z4 (медиана 24 мин Z3+), рядом с порогом и МПК. Фазы II–III, дистанции от 10 км; Горки Z5 (короткие) остаются как есть. Горки: фаза II через неделю вместо R (и вместо T при рельефе), верхняя цель.
- Каждая тренировка берёт минуты из целей по зоне своих элементов: Z3 и Z4 — средняя цель, Z5 — верхняя (5.4); цель = доля × минуты недели (раздел 4.4). Гонка недели расходует цели по зоне своего темпа (5.4), как тренировка в том же темпе. Интенсивный кросс (К2) — половина его времени в Z4, расходует среднюю цель; К2 «авто» резервирует её при расчёте состава, до выбора дней. В фазе I возможный вариант К1 определяется заранее в разделе 4.5. Сумма качественных и длинной не больше объёма недели (+5 мин); качественная, которая не влезает, считается невместившейся (примечание об ограничении состава).

#### 5.5.4. Длительности тренировок и число пробежек

- **Длинная:** прогрессия +10 мин в неделю (Пфитцингер: ~1 миля в неделю), но не больше +10% к прошлой обычной длинной (минимальная прибавка 5 мин — сетка плана; результат округляется к ближайшим 5 мин, половина — вниз). Если после этого самая длинная пробежка марафонского или ультра-плана короче 120 мин (ориентир 2–2,5 ч), в примечания идёт предупреждение: за срок плана от привычной длинной больше не набрать — нужно больше недель или более длинная привычная (`curLong`); не выводится, если длинная упёрлась в `maxLongCap`: скачок дистанции одной пробежки — предиктор травм (Frandsen et al. 2025; числа — ниже, «Справочно»); начало — длинная привычная (`curLong`) или привычная доля длинной от текущего объёма (30% при < 64 км, иначе 25%, Дэниелс; доля марафона и ультра 40% — потолок роста, а не точка старта); в неделях А и Б — по волне раздела 4.4, в подводку — длинная пика × доля. Нет длинной, если на её день выпал старт или тест, в неделе промежуточный старт на 21,1 км и длиннее (гонка заменяет длинную), её день в окне восстановления (после 5–10 км окно короче длинной не мешает), в неделе нет допустимого дня для неё (5.6), длинная короче 30 мин или заданное число пробежек уже занято стартом и выездом.
- **Справочно (в правила не входит): длинная, восстановление и травмы.**
  - Нейромышечный спад зависит от длительности нелинейно: при 5 ч бега на 55% МПС сила достоверно упала только после 4-го часа ([запись исследования](https://lida.sport-iat.de/ta/Record/4008772)); в беге на 20 км на максимум — только в последние 5 км ([Ross et al.](https://nrl.northumbria.ac.uk/id/eprint/4180)); после 166 км сила упала на 35–39%, восстановление ~16 суток ([Millet 2011](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0017059)). Повреждение мышц растёт с длиной гонки, но не по всем маркерам ([Martínez-Navarro 2020](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0238846), [Knechtle & Nikolaidis 2018](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2018.00634/pdf)). После марафона маркеры нормализуются за 1–3 дня, в основном за неделю ([обзор 2025](https://link.springer.com/article/10.1186/s40798-025-00810-3)); лёгкий бег через 48 ч восстановлению не мешает ([RCT](https://pubmed.ncbi.nlm.nih.gov/33251988/)). Зависимости времени восстановления от длительности лёгкой длинной 1,5–3 ч в источниках не найдено.
  - Риск травм связан со скачком, а не с абсолютной длиной: пробежка длиннее самой длинной за предыдущие 30 дней на 10–30% — HRR 1,64, на 30–100% — 1,52, более чем на 100% — 2,28; недельный скачок нагрузки с травмами не связан ([Frandsen 2025](https://pure.au.dk/portal/en/publications/how-much-running-is-too-much-identifying-high-risk-running-sessio/)). Абсолютная длина самой длинной и объём с травмами не связаны ([Fokkema 2020](https://repub.eur.nl/pub/127621/Repub_127621_O-A.pdf)). Оба исследования наблюдательные, травмы самоотчётные. В исследовании опора — самая длинная за 30 дней; в правиле выше опора — прошлая обычная длинная.
- **Совместный формат длинной:** полная длительность, лёгкая часть, вставки и паузы определяются одновременно в бюджете недели. Порядок задаёт деление плана по специфике: в общей части (фазы I–II) длинная растёт только по длительности, вставок нет; со специфической части (фазы III–IV) подключаются вставки как доля уже достигнутой длительности, поэтому рост длительности не прерывается и не укорачивается. Готовую длинную не укорачивать постфактум ради добавленных вставок. Истории полной длительности и интенсивной части раздельны; достигнутая лёгкая длительность не обнуляется более коротким интенсивным вариантом. Доступные форматы:
  - марафон, фаза III — отрезки T по 10′ с 2′ трусцой; работа = доля длинной по лестнице 25 → 35 → 45 → 55 → 65%, но не больше лимита T, остатка целей и длинной − 30 мин; кратно 10′;
  - марафон, фаза IV — M в конце длинной; та же лестница, лимит M; в лёгком темпе остаётся ≥ 30 мин;
  - ультра, фаза IV — целевой темп в конце длинной;
  - эти доли задают доступные форматы, а не обязательную календарную лестницу. Совместный формат длинной выбирается из бюджета по предыдущей полной дозе и назначению недели; в подводке сохраняется назначение при снижении дозы;
  - до выбора длинной со вставками резервируются предусмотренные блоком поддерживающие дозы остальных качеств.
- **Средне-длинная** (полумарафон, марафон и ультра, фазы II–IV): 60% длинной (Пфитцингер), не больше 120 мин (ультра — 180); только если выходит ≥ 60 мин, недельный объём ≥ 50 км (4.5.6), после неё остаётся хотя бы одна пробежка на длинную, и её день — не предстартовый и не в окне восстановления.
- **Средне-длинная с отрезками T** (MQ): длительность — как у средне-длинной; в конце n × 10′ T с 2′ трусцой; работа = min(рабочие минуты ступени, остаток целей, лимит T, длительность − 30 мин), кратно 10′; ступень — доля длительности по лестнице «Вставки в длинной» (25 → 35 → 45 → 55 → 65%), переходы — по правилу «Переход» ниже **[практ.]**; в лёгком темпе остаётся ≥ 30 мин; ставится, если остался бюджет качественных. Если не помещается ни один отрезок — обычная средне-длинная, качественная считается невместившейся (примечание об ограничении состава).
- **Лёгкие и восстановительные:** количество, дозы и признак второй пробежки определяются в составе раздела 4.5; дни выбираются в разделе 4.6. Дни окна восстановления: потолок дня растёт от 30 мин в первый день до 75 мин в последний, не выше потолка лёгкой **[практ.]**: окно — лёгкие дни (Дэниелс), 30 мин — минимум пробежки в первый день после гонки. Потолки: лёгкая — min(средне-длинная, 60% длинной) **[практ.]**: лёгкая заметно короче длинной, чтобы длинная оставалась отдельным стимулом по длительности; восстановительная — min(~8 км в медленном конце E, лёгкая) (Пфитцингер: 4–7 миль); без длинной — обычная лёгкая прошлой рабочей недели. Потолок дня со второй пробежкой — длительность длинной недели (раздел 4.6). Минуты раздаются «водой» (раздел 4.5.8), затем по +5 мин — сначала лёгким, потом восстановительным.
- **Число пробежек в форму** — наибольшее число пробежек за недели до подводки при автоматическом подборе.

#### 5.5.5. Лестницы форматов и прогрессия

Каждый тип — лестница ступеней от лёгкой к тяжёлой. Форматы — по Дэниелсу:

- T — крейсерские отрезки 5–15 мин (отдых 1 мин на каждые 5 мин) и темповый 20 мин;
- I — отрезки 3–5 мин, трусцой столько же;
- R — 200–400 м, отдых вдвое дольше;
- M — непрерывно.

Порядок ступеней — по объёму работы **[практ.]**: следующая ступень даёт больше работы в темпе типа, поэтому рост нагрузки идёт ровно:

| Тип | Ступени |
|---|---|
| T | 3×5′, 4×5′, 20′, 3×8′, 3×10′, 2×15′, 4×10′, 3×15′, 5×10′, 4×15′ |
| Темп полумарафона | 2×10′, 2×12′, 3×10′, 2×15′, 3×12′, 2×20′, 3×15′, 2×25′, 3×20′ (отдых 2 мин) |
| M | 30′ … 110′, прибавка 10′ |
| Steady | 30′, 40′, 50′, 60′, 75′, 90′ |
| Ультра-темп | 30′ … 105′, прибавка 15′ |
| I | 4×3′, 5×3′, 4×4′, 6×3′, 5×4′, 4×5′, 6×4′, 5×5′, 6×5′ |
| R | 8×200, 10×200, 6×300, 8×300, 6×400, 8×400, 10×400, 12×400, 16×400, 20×400 м |
| Темп 10 км | 5×1000, 6×1000, 4×1600, 3×2000, 5×1600, 4×2000 м (отдых 2 мин, от 1600 м — 3 мин) |
| Темп 5 км | 6×600, 5×800, 6×800, 5×1000, 6×1000 м |
| Порог в горку | 3×4′, 3×6′, 3×8′, 4×6′, 4×8′ (вниз трусцой столько же, по усилию порога) |
| Горки | 6×60″, 8×60″, 6×90″, 8×90″, 10×90″, 8×120″ (вниз трусцой 1,4× времени подъёма, по усилию RPE 8/10) |
| Вставки в длинной | 25, 35, 45, 55, 65% длинной |

- **I** переводится в дистанцию: ближайшая из 400–1600 м к длительности ступени, не длиннее 5,5 мин.
- **Разминка и заминка отдельной Q:** 15 и 10 мин **[практ.]**: время, за которое пульс и кровоток выходят на рабочий уровень, и возврат к покою. Исключения для стартов — 5.5.6.
- **Отдых между отрезками** — трусцой, Z1:
  - T — 1 мин на каждые 5 мин отрезка;
  - I — равен отрезку, округление до 30 с;
  - R — вдвое дольше отрезка;
  - темп полумарафона и T в длинной — 2 мин;
  - темп гонки — 2–3 мин.
- **Полная длительность отдельной Q** = разминка 15 + работа + паузы + заминка 10 мин. У длинной со вставками и средне-длинной с отрезками T разминки нет.
- **Прогрессия по назначению [практ.]:** протокол хранит рабочие минуты, длину отрезков, темп, паузы, полную длительность и последнюю выполненную ступень. Ступени лестницы упорядочены по объёму работы в темпе типа, поэтому переход вверх — на следующую ступень.
- **Начальная доза** назначения — первая ступень лестницы его типа (длинная — `curLong`, вставки в длинной — 25%); не помещается — см. «Первая ступень не помещается» ниже. История по типам не вводится: в начале плана последним стимулом каждого качества считается начало плана.
- **Переход:** с последней выполненной ступени того же назначения на следующую, ступени не пропускаются. На последней ступени, в подводку и в неделю старта — повтор; не хватает бюджета — уменьшенная доза (меньше повторов, ≥ 2, или короче отрезок): из ступеней до последней и их уменьшений берётся наибольшая в пределах лимита недели, а не нижняя ступень. Если прошлые дозы были уменьшены под лимит и ступень не записана, потолком служат их фактические рабочие минуты. Темп и паузы меняются только вместе со ступенью. Так подводка сохраняет Z3+ (пример: Higdon марафон Adv1, вторая неделя подводки: порог 3×8′ вместо 2×5′, Z3+ 36% → 49% базы).
- **Опорная доза поддержания:** последняя развивающая; если развивающей ещё не было — первая ступень лестницы. Поддержание — тот же формат, уменьшенный (меньше повторов, ≥ 2, или короче отрезок) до рабочих минут не ниже n·`f` опорной (`f` — доля назначения, n — интервал до следующего стимула в неделях, n ≤ 1/`f`) и не ниже минимальной работы (таблица выше); выше опорной не бывает.
- Изменение темпа, рабочих минут и плотности не считать независимыми бесплатными прибавками. Их сочетание должно быть предусмотрено выбранным протоколом.
- **Подводка и неделя старта** — доза не выше последней сопоставимой, в пределах бюджета; последовательность форматов сама по себе не определяет трудность.
- **Первая ступень не помещается** — тот же формат с меньшим числом повторов (≥ 2) или более короткий непрерывный отрезок.

#### 5.5.6. Главный и промежуточные старты

- старт;
- накануне — лёгкий выезд 20 мин + 3 ускорения;
- за 2 дня — отдых;
- за 5 дней — настройка. Она приоритетнее обычной работы: если день −5 в предыдущей неделе (старт в пн–пт), она ставится там по дате вместо обычной качественной (метка через границу недель, как предстартовые), настройка входит в фиксированный состав и расходует бюджет качественных: 10 км и короче — интервалы 3–4×400 м в темпе гонки; полумарафон — 3×1000 м в темпе полумарафона; марафон — 3×1000 м в марафонском темпе; отдых 90 с. У ультра и в окне восстановления — лёгкий 30 мин + 4 ускорения;
- остальные дни — лёгкие, не длиннее лёгких последней недели подводки (без подводки — не длиннее 45 мин); ближайшая к старту — с ускорениями;
- разминка на старте: полумарафон и длиннее — 10 мин (бережёт гликоген), 5–10 км — 15 мин и 3 ускорения; заминка — 5 мин после полумарафона, 10 мин после 5–10 км, после марафона и ультра — нет;
- промежуточный старт: разминка 15 мин, 3 ускорения, заминка 10 мин (с 42 км — без заминки).
- Реализация: `composeWeek` (состав, шаблон, заполнение), `buildWeek` (число пробежек), `LAD`, `DL`, `WORK_MIN`, `TPL`.

### 5.6. Шаблон недели

#### 5.6.1. Каталог составов

Обозначения: E — лёгкая, R — восстановительная, Q — конкретная отдельная качественная, M — лёгкая средне-длинная, MQ — средне-длинная с заранее выбранной качественной частью, L — лёгкая длинная, LQ — длинная с качественной частью, F — фиксированные занятия календаря. Знак «+» означает два отдельных занятия дня; MQ и LQ — по одной тренировке. Для каждого Q сохраняется его назначение и доза.

| Семейство | Обязательные беговые занятия | Дополнение до числа пробежек |
|---|---|---|
| Восстановление / неделя без длинной | F, если есть | Заданные E/R |
| Лёгкая неделя | L | Заданные E/R |
| Отдельные качественные | 1–2 Q, L | Заданные E/R |
| Со средне-длинной | 0–2 Q, M, L | Заданные E/R |
| Качественная длинная | 0–1 Q, LQ; M при наличии в составе | Заданные E/R |
| Качественная средне-длинная | 0–1 Q, MQ, L | Заданные E/R |
| Две объединённые качественные | MQ, LQ | Заданные E/R |
| Ультра со спаркой | M и L/LQ в соседние дни, 0–2 Q в пределах бюджета | Заданные E/R |
| Старт / тест / настройка | F и остальные заранее выбранные занятия | Заданные E/R |

Семейство определяется точным составом, а не дистанцией и фазой. Дистанция и фаза уже учтены при выборе доз в разделе 4.5. Q, MQ, LQ, гонка и отдельный К2 расходуют бюджет качественных дней; при 3 пробежках он равен 1, иначе не больше 2. Состав с превышением бюджета не передаётся в выбор шаблона. Ультра-спарка допустима только при явном назначении в составе.

#### 5.6.2. Полное множество шаблонов

- Для заданного состава рассматриваются размещения по семи календарным дням, включая допустимые вторые пробежки. Пробежек ровно столько, сколько задано составом; число занятых дней — отдельный результат размещения. Одинаковые занятия можно переставлять без создания дубликатов.
- Предварительно фиксируются гонки, тесты, выезды, отдых, настройка и кросс в заданные дни. День длинной — `longDow` (по умолчанию день недели главного старта, 3.1; в таблице ниже — воскресенье); он не сдвигает фиксированные занятия календаря. Это предпочтение: если в неделе день длинной смежен с тяжёлым фиксированным занятием (старт, тест, настройка), длинная переносится на ближайший день, где ограничения ниже выполнены; если такого дня нет — неделя без длинной (5.5).
- Остальные занятия перебираются по свободным допустимым позициям. При каждом размещении используются уже известные ограничения конкретного занятия; заведомо недопустимые ветви не создаются. Совмещение занятий разрешается только если оно предусмотрено составом.
- Если в разделе 4.5 явно разрешены несколько дат длинной или способов совмещения, рассматриваются эти варианты. Сам выбор шаблона новых разрешений не добавляет.
- Базовые строки ниже — результат применения правил этого раздела (длинная в воскресенье): типичный результат критериев (раздел 5.6.5.5 зависит от доз, при других дозах выбор может быть иным); другие равноценные по источникам допустимы. Это не закрытый список. Полноту обеспечивает перебор состава.

#### 5.6.3. Обязательные ограничения размещения

- Состав, назначения, дозы и число пробежек сохраняются полностью. Фиксированные даты, недоступные дни и окна восстановления не нарушаются.
- **Тяжёлые занятия** — Q, MQ, L, LQ, гонка, тест, настройка, отдельный К2. Между любыми двумя тяжёлыми — минимум один нетяжёлый день (E, R, M, отдых, К1/К4), в том числе через границу недель. Источник: Дэниелс — E-дни между Q-занятиями ([Daniels' Running Formula, отрывок](https://us.humankinetics.com/blogs/excerpt/sample-running-program-from-daniels-running-formula)); так построены недели Дэниелса, Пфитцингера, 80/20, Great Run и (по файлам) Hansons. Garmin (5 планов из 5) и Higdon ставят Q или темп гонки накануне длинной: в файлах эталонов (кроме Hansons) накануне L стоит 58 из 220 сессий Q (Garmin 35 из 111, Higdon 13 из 47, BHF 10 из 57), у Higdon 10 км Advanced есть и две Q подряд (8 пар). Причины такого размещения в этих планах не приведены, поэтому правило остаётся основным; **запасной шаблон [практ.]:** если строгого размещения нет (в том числе для третьей Q при ≥ 7 пробежках), допускается одна Q накануне L, но не после неё и не вторая подряд; это дешевле потери Q (4.5.10). Это минимум, а не оптимум: после 6×800 м большинство бегунов восстановилось за 24 ч, часть — нет, авторы рекомендуют индивидуальную оценку ([Riazati 2022](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2022.830278/pdf)). Согласованная пара К2 + Q считается одним днём с суммарной нагрузкой. В строгом шаблоне Q не ставится накануне и сразу после L — следует из правила.
- **Средне-длинная M** не считается тяжёлой для этого правила (у Пфитцингера она идёт на следующий день после порога), но не ставится накануне и сразу после L/LQ **[практ.]**: в эталонной неделе Пфитцингера M и L разделены тремя днями ([Pfitzinger 18/55](https://ctyeh.com/articles/2754?lang=en)). Исключение — явно назначенная в составе спарка (ультра; у Hansons back-to-back средне-длинные для накопленной усталости, [Hansons](https://marathonhandbook.com/hansons-marathon-method/)).
- Учитываются фактические занятия на границах недели: известный конец предыдущей и фиксированное начало следующей. Ограничения проверяются по датам, включая сдвинутый день длинной.
- Вторые пробежки — только заданные R; не более двух пробежек в день. Запрещены в день M/MQ, L/LQ, старта, теста, кросса и в окне восстановления. Сумма беговых минут дня не выше потолка дня: длительности длинной недели (длинная остаётся самым нагруженным днём — тот же смысл, что у потолка лёгкой, 5.5); в неделе без длинной — потолка лёгкой **[практ.]**; каждая пробежка соответствует своим минимуму и максимуму.
- R+Q сохраняет интервал между занятиями, предусмотренный протоколом. Утренний R и последующая Q — условие такого совмещения, а не основание добавлять R после выбора шаблона.
- Кросс и силовые участвуют в доступности дня и требованиях восстановления; они не добавляются поверх уже выбранного расписания без учёта этих ограничений. К3 и силовые в один день допускаются только при явно согласованном составе.
- Предстартовый отдых и выезд, настройка и восстановление имеют приоритет фиксированных меток. Конфликт с дозой возвращается как невозможность размещения; Q не превращается в E автоматически.

#### 5.6.5. Выбор среди допустимых шаблонов

Сравнение лексикографическое, без суммы произвольных весов. Сначала строгие шаблоны (5.6.3); запасной (Q накануне L) рассматривается, только если строгих нет, и в нём меньше таких Q — лучше. Кандидаты уже допустимы до ранжирования; ранжирование не исправляет нарушения, не отбрасывает занятия и не меняет бюджет.

**5.6.5.1.** Меньше дней со второй пробежкой **[практ.]**: если те же дозы можно разместить по одной пробежке в доступные дни в пределах уровня, выбрать такой вариант.

**5.6.5.2.** Меньше изменений привычных дней бега и закреплённых предпочтений пользователя; фиксированные ограничения уже выполнены. Работает, только если такие дни заданы; в форме сейчас их нет (кроме `longDow` и дней кросса), тогда критерий пропускается.

**5.6.5.3.** Совпадение с эталонами источников: для каждого занятия (Q, MQ, M, R, L, LQ) число эталонных недель и сессий файлов, где оно стоит в этот день (столбец «Сумма» таблицы выше); берётся шаблон с наибольшей суммой совпадений. E не оценивается.

**5.6.5.4.** При ≥ 5 днях бега накануне длинной — лёгкий бег (E или R), а не день отдыха **[практ.]**: в эталонной неделе Пфитцингера накануне длинной два восстановительных бега; в файлах эталонов при ≥ 5 днях бега накануне длинной отдых или кросс — 8 из 163 недель (лёгкий бег — 86, Q — 69). При ≤ 4 днях бега критерий не применяется: отдых или кросс накануне длинной — 35 из 71 недели (лёгкий бег — 18, Q — 18).

**5.6.5.4а.** При ≥ 4 днях бега — не более 2 дней без бега подряд в неделе **[практ.]**: в эталонах максимум подряд без бега ≤ 2 в 19 из 21 планов (3 — Hansons полумарафон, оба уровня). Недели старта, настройки и окна восстановления не учитываются.

**5.6.5.5.** Меньше максимальная сумма расчётной нагрузки двух последовательных дней, включая известную границу прошлой недели **[практ.]**. Критерий выбора размещения, не самостоятельный предиктор травм и не повод менять дозы.

**5.6.5.6.** Больший минимальный интервал между тяжёлыми днями **[практ.]**. Применяется только при равенстве по разделам 5.6.5.1–5.6.5.5: у Пфитцингера и в 80/20 интервал не максимален (вт и вс), поэтому как главный он источникам противоречит.

**5.6.5.7.** При полном равенстве — сравниваются векторы дат занятий в порядке их идентификаторов в составе, выигрывает меньший вектор (раньше по календарю): одинаковые вводные дают одинаковый шаблон.

Если несколько шаблонов равны по разделам 5.6.5.1–5.6.5.4, они считаются равноценными по источникам; выбор между ними определяется правилами разделов 5.6.5.5–5.6.5.7. Если кандидатов нет, возвращаются конфликтующие ограничения; состав пересматривается только в разделе 4.5 в порядке, заданном в разделе 4.5.10 в пределах разрешённых протоколом вариантов.

#### 5.6.6. Кросс-тренировки

Класс задаётся в форме; нагрузку определяют интенсивность и мышечная работа, а не вид спорта **[практ.]**:

| Класс | Что | Нагрузка за минуту (ACWR) | Роль в неделе |
|---|---|---|---|
| К1 | аэробная лёгкая, Z1–Z2 (вело, плавание, эллипс, лыжи, гребля, аква-бег) | как лёгкий бег (TRIMP 2) | лёгкий день |
| К2 | аэробная интенсивная, Z3–Z5 | TRIMP 3: половина времени в Z2, половина в Z4; эта половина расходует среднюю цель (Z4, 5.4) | качественный день |
| К3 | силовая / функциональная | 0 (как силовые) | как силовая |
| К4 | восстановительная (йога, мобильность) | 0 | любой день |

- Кросс в беговые минуты и км недели не входит; в ACWR — входит по классу; при калибровке Garmin К1 — по нагрузке лёгкого бега, К2 — порога.
- Доля Z3–Z5 в К2 — половина **[практ.]**: интенсивная кросс-тренировка — это интервалы с отдыхом, а не сплошная работа выше VT1.
- Длительность пропорциональна объёму недели относительно пика (0,5–1), не меньше 20 мин.
- В окне восстановления и за 1–2 дня до старта К2 становится К1 (по той же причине, по которой там нет беговых качественных). В неделе главного старта — только К4.
- **Фиксированные дни** не переносятся. Отдельный К2 занимает качественный день; пара К2 + Q допустима только если заранее согласована в составе с суммарной дозой. Размещение учитывает соседние тяжёлые дни и длинную. Конфликт возвращается при выборе кандидатов, а не исправляется автоматической сменой типа занятия.
- **«Авто»** — по очереди К2 → К3 → К1 → К4:
  - К2 — второй тренировкой в день Q (или средне-длинной с отрезками T), после которого не идёт тяжёлый день (тяжёлый день становится тяжелее, лёгкие остаются лёгкими; Дэниелс 2Q). Без пары — отдельным днём, соседи которого не тяжёлые, если бюджет качественных не исчерпан; если размещение невозможно — причина возвращается в раздел 4.5; вариант К1 допустим только как заранее разрешённая альтернатива состава;
  - К3 — день Q не накануне тяжёлого дня; иначе день E или R не накануне тяжёлого, дальний от тяжёлых; затем любой день Q, любой день E или R, выходной;
  - К1 — день отдыха после тяжёлого дня (активное восстановление), другой день отдыха, день E или R, дальний от тяжёлых, в последнюю очередь — день Q или средне-длинной; последний полный выходной не занимается;
  - К4 — любой день, кроме старта.

Допустимые позиции кросса «авто» и силовых определяются для конкретных Q/MQ/LQ/E/R выбранного состава по правилам выше; кандидат без места для них по спискам выше отбрасывается; в ранжировании кросс и силовые учитываются нагрузкой в разделе 5.6.5.5 и (К2) как тяжёлый день в разделе 5.6.5.6. Силовые размещаются по правилу К3 «авто». К2 на К1 ради размещения не меняется: такой альтернативный состав заранее разрешается в разделе 4.5.

#### 5.6.7. Силовые

- **Число в неделю [практ.]:** базово 2; ультра или объём > 120 км — 1; новичку при марафоне и длиннее или при объёме > 80 км — 1; не меньше 1. Чем больше беговой нагрузки, тем меньше места для восстановления после силовой.
- Наборы: A (25 мин), B (20), C (20), кор (15).
- В подводке — один кор. В неделе старта — один кор не позже чем за 5 дней до старта. В дни восстановления — кор.

### 5.7. Заполнение

- Вторые тренировки в день — восстановительные (флаг `dbl2`).

### 5.8. Контроль нагрузки

- **ACWR** = нагрузка недели / средняя недельная нагрузка за 4 недели, включая текущую (как в отчёте приложения; в ограничении роста — с полом знаменателя, раздел 4.4). Зелёная зона 0,8–1,3 (Gabbett 2016, командные виды спорта; у формулы есть критика — [Impellizzeri et al. 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7534938/) — поэтому порог для бега **[практ.]**). В плане ACWR не выше 1,3.
- **Ограничение недели:** acute ≤ max(1,3·h3 / (4 − 1,3); 1,3·L_min), где h3 — нагрузка трёх прошлых недель, L_min — нагрузка минимальной недели (раздел 4.4.3): хроническая нагрузка в знаменателе не меньше L_min.
- **Нагрузка без калибровки** — TRIMP Эдвардса (Edwards 1993, книга «The Heart Rate Monitor Book»; пять зон с весами 1…5, [описание](https://sportsmedicine-open.springeropen.com/articles/10.1186/s40798-022-00498-9/tables/2)): минуты в Z1…Z5 с весами 1…5; у Эдвардса зоны — по % HRmax, здесь — по шкале от ПАНО. Источник сам отмечает, что коэффициенты не имеют физиологического обоснования. Зона элемента тренировки определяется по его цели:
  - цель — пульс: номер зоны;
  - цель — темп: зона по темпам недели (границы — раздел 5.4).
  - Для оценки без элементов тренировки: восстановительный 1, лёгкий, длинная и К1 2, К2 3, M и steady 3, T 4, I, R, горки и гонка 5 на минуту.
- **Нагрузка с калибровкой Garmin** — минуты × нагрузка/мин типа тренировки, в единицах истории Garmin; ключи `lpm`: лёгкий, восстановительный и К1 — `easy`; длинная — `long`; T, M и К2 — `thr`; I, R, гонка и горки — `vo2`; отсутствующие: `long` → `easy`, `thr` → `easy`, `vo2` → `thr`.
- Силовые и К3, К4 в ACWR не входят.
- **История до плана:**
  - с калибровкой — реальная нагрузка Garmin за 28 дней; разрыв между концом истории и началом плана — от −27 до +14 дней, недостающие дни — нули;
  - без неё — текущий объём × средняя нагрузка/мин распределения плана плюс кросс;
  - при переходе с другой программы не раньше чем 3 недели назад в историю подставляется её пиковая неделя.
- **Как учитывается:** при построении кривой (раздел 4.4) — по нагрузке собранной недели: объём недели — наибольший, при котором она проходит; история — нагрузки собранных прошлых недель. После построения ничего не урезается. Подводку ACWR не проверяет: нагрузка в ней падает.
- Неделя промежуточного старта может быть выше 1,3: нагрузку самой гонки не убрать.

### 5.9. Оформление

#### 5.9.1. Питание

Запаса гликогена хватает примерно на 75–90 мин работы, дальше без углеводов падает темп; поэтому:

- на пробежках от 75 мин;
- по Jeukendrup ([рекомендации](https://www.mysportscience.com/post/2015/05/27/recommendations-for-carb-intake-during-exercise)): 1–2 ч — около 30 г/ч, 2–2,5 ч — до 60 г/ч, дольше 2,5 ч — до 90 г/ч; ступени одни для тренировок и гонки, по ожидаемой длительности; кишечник тренируют заранее. Масштаб по весу в источнике не задан и не применяется;
- порция геля: 40 г (глюкоза + фруктоза) при потребности > 55 г/ч, иначе 20 г — выше 60 г/ч нужна смесь разных типов углеводов (Jeukendrup);
- в гонке питание нужно только от полумарафона.

#### 5.9.2. Итоги и примечания

- Анализ плана: VDOT каждого результата, исходный и прогнозируемый профиль, лучший VDOT как верхняя граница, траектория роста формы и ориентир времени с диапазоном; уровень 80/20, бюджеты и фактические зоны, поддерживающие и развивающие дозы по назначениям; пик, ограничения роста и состава, разгрузки, подводка, частота, пульсовые зоны.
- Примечания: объём и уровень, ограничения роста и состава, дефицит и акценты развития без исключения других качеств, недоступные поддерживающие дозы, ориентировочный характер прогноза, диагностика Тэнды в пределах выборки, контрольный тест, неполная неделя.

#### 5.9.3. Запись тренировок

- **Зоны 1–2** (лёгкий, восстановительный, длинная, средне-длинная, разминка, заминка) — по времени, кратно 5 мин. Длительности разминки и заминки уже выбраны в разделе 4.5 (5.5.5); оформление их не меняет.
- **Зоны 3–5** (M, steady, T, темп полумарафона) — по целевому темпу, длительность отрезка в целых минутах.
- **МПК, повторы, интервалы в темпе гонки** — по дистанции.
- Разминка, заминка и паузы записываются в дозах, выбранных в разделе 4.5 (5.5.5).
- Зоны длинной берутся из распределения интенсивности (5.4.1); оформление их не меняет.
- **Цели Garmin:** зоны 1–2 — зона пульса Z1–Z2; зоны 3–5 — темп; горки — зона пульса Z5 с подсказкой по усилию. Пульс в уд/мин от ПАНО показывается справочно и в цели не пишется. Доли ПАНО — зоны Friel (Training Peaks, [«Quick Guide to Setting Zones»](https://www.trainingpeaks.com/learn/articles/joe-friel-s-quick-guide-to-setting-zones/): Z1 < 85%, Z2 85–89%, Z3 90–94%, Z4 95–99%, Z5 ≥ 100% LTHR); нижняя граница Z1 и верх Z5 — для показа:

| Зона | Z1 | Z2 | Z3 | Z4 | Z5 |
|---|---|---|---|---|---|
| Доля ПАНО | 0,65–0,84 | 0,85–0,89 | 0,90–0,94 | 0,95–0,99 | 1,00–1,06 |

Потолок — HRmax, если он выше ПАНО.

- **Элементы тренировки** — формат, совместимый с `garmin_plan_import.py`: warmup / interval / recovery / cooldown / repeat, окончание по времени или дистанции, цель — зона пульса или темп.

## 6. Межсезонье (`buildOffseasonPlan`) [практ.]

Отдельный режим (`planMode = offseason`): без прогноза и темпов типов. Бег — по времени и зоне пульса, силовые — фиксированные наборы. Цель — сохранить аэробную базу при сниженном объёме и набрать силу, которую в беговом сезоне развивать некогда.

**6.1.** **Длительность:** новичок 2–3 недели, средний 3–4, опытный 4–6. Если недавний объём был очень высоким (от 55 / 90 / 130 км для новичка / среднего / опытного) — на неделю больше.

**6.2.** **Поддерживающий объём** — 50–65% текущего (берётся середина), не ниже ~15–20 км в неделю. Если текущий объём уже ниже, он только слегка снижается.

**6.3.** **Частота:**

  - силовые — 3 в неделю (новичок — 2);
  - бег — 2 у новичка, 3 у среднего и опытного при объёме меньше 25 км, иначе 4.

**6.4.** **Под-фазы силовой:** втягивание (~25–30%, минимум 1 неделя; объём бега 85% в первую неделю, 95% во вторую) → максимальная сила (~45–55%) → сила-мощность (~20–25%). Последняя — мост обратно в базу: объём бега +12,5% в неделю. В коротких циклах фазы ужимаются, но каждая сохраняет хотя бы неделю.

**6.5.** **Дни силовых:** 1 в неделю — среда; 2 — понедельник и четверг; 3 — понедельник, среда и пятница. Если день длинной совпадает с силовой, силовая сдвигается (порядок: Чт, Пн, Сб, Вт, Пт, Ср, Вс).

**6.6.** **Длинная** ≈ 1,4 средней пробежки. Ускорения — на последнем беговом дне, после втягивания. Часы в км — по середине E из VDOT по ПАНО (5.1).

Формат недель и тренировок тот же, что у `buildPlan`, поэтому редактор и экспорт работают одинаково.

## 7. Прочие модули

### 7.1. Возврат после травмы или болезни

(`adaptRecovery`) — адаптация загруженного плана по запросу пользователя **[практ.]**: после перерыва ткани и аэробная система теряют адаптацию быстрее, чем набирают, поэтому нагрузка возвращается постепенно:

- потолки по неделе возврата k (от 0): длинная 40 + 15k, лёгкая 35 + 8k, восстановительная 25 + 8k мин; ударные травмы и стресс после гонки — ×0,8; не короче 20 мин;
- качественные и старты в окне — лёгкие (старт снимается с предупреждением), силовые — кор (при спине — без осевой нагрузки);
- ускорения — со 2-й недели, в темпе конкретного бегуна (из сохранённого cfg), окно −6% … 0;
- вторые пробежки дня (флаг `dbl2`) убираются;
- кросс сохраняется.

### 7.2. Редактор

модалка редактирования элементов тренировки. Таблица недель и графики строятся из `EDIT`: это единый источник. Дни без тренировок показываются как отдых (в выгрузку не идут).

### 7.3. График ACWR

по неделям плана, 7 / 28 дней, хроническая нагрузка = сумма за 28 дней / 4.

- История — та же, что в проверке 5.8: с калибровкой — реальные 28 дней Garmin; без неё — текущий объём × средняя нагрузка/мин. `START_ACWR` — только стартовая точка графика (0,8, если данных о нагрузке нет).
- Нагрузка — тот же `loadPerMin`, что в генераторе.

### 7.4. Загрузка плана

- проверка записей (бег без элементов тренировки отклоняется);
- форма восстанавливается из `meta.cfg`, включая старые форматы (`cur10`/`tgt10`/`tgtMar`/`marathonISO`) и класс кросса, с безопасными значениями по умолчанию;
- без cfg даты и старты восстанавливаются по тренировкам. Главный старт — последний по дате; дистанция берётся только из названий гонок.

### 7.5. Тег плана

дистанция + время + суффикс даты начала `-ММДД`, например M315, H132, T40, U6…U16. Два плана с одинаковой целью не перетирают друг друга в Garmin и intervals.icu; повторная заливка того же плана заменяет сама себя.

### 7.6. Экспорт

HTML плана и plan.json через data:-URI: Android-приложение перехватывает скачивание только по data:-ссылкам.

### 7.7. Экранирование

`esc()` — & < > " '. Названия тренировок пользователь может править.

### 7.8. Определение типа тренировки по названию

(`zoneOfW`, для загруженных планов):

- старт или контрольный → race;
- «Длинн» → long;
- «МР», «Марафонск», «Ультра-темп», «Стэди» → mp;
- «Порог», «Темп», «Стабильн» → thr;
- «МПК», «Интервал», «Повтор», «Горк», «Подъём» и т.раздел → vo2 (горки — короткая работа в Z5);
- «Восстанов» → rec;
- иначе easy.
